# 第三章 平面问题与三角形单元

## 3.1 平面问题分类

```
  ┌──────────────────────────────────────────────────┐
  │  平面应力（Plane Stress）                         │
  │  条件：厚度很薄，面外应力 σ_z ≈ 0               │
  │  例如：薄板、薄壁结构                             │
  │  σ_z = τ_xz = τ_yz = 0                          │
  │                                                  │
  │  平面应变（Plane Strain）                         │
  │  条件：长度很长，面外应变 ε_z ≈ 0                │
  │  例如：水坝、隧道、挡土墙截面                     │
  │  ε_z = γ_xz = γ_yz = 0                          │
  └──────────────────────────────────────────────────┘
```

```
    平面应力（薄板）：         平面应变（长体）：
    
    ┌──────────┐              ════════════════
    │          │ 薄            ║              ║
    │  σ_x,σ_y│              ║  σ_x,σ_y    ║ 长
    │  τ_xy    │              ║  τ_xy        ║
    └──────────┘              ║              ║
      σ_z ≈ 0                 ════════════════
                               ε_z ≈ 0
```

### 弹性矩阵 D

平面应力：
```
         E     ┌ 1   μ    0       ┐
  D = ─────── │ μ   1    0       │
      1 - μ²  └ 0   0   (1-μ)/2  ┘
```

平面应变：
```
         E(1-μ)       ┌  1      μ/(1-μ)    0           ┐
  D = ─────────────  │ μ/(1-μ)   1        0           │
      (1+μ)(1-2μ)    └  0        0       (1-2μ)/[2(1-μ)]┘
```

## 3.2 三节点三角形单元（CST）

### 单元描述

```
    CST 单元（Constant Strain Triangle）：
    
    3(x₃,y₃)
    │╲
    │  ╲
    │    ╲        3 个节点
    │      ╲      6 个自由度（每节点 u, v）
    │        ╲    单元内应变为常数
    │          ╲
    1───────────2
    (x₁,y₁)   (x₂,y₂)
    
    节点位移向量：
    u_e = [u₁, v₁, u₂, v₂, u₃, v₃]^T
```

### 形函数（Shape Function）

```
  单元内任意点的位移用节点位移插值：
  
  u(x,y) = N₁·u₁ + N₂·u₂ + N₃·u₃
  v(x,y) = N₁·v₁ + N₂·v₂ + N₃·v₃
  
  ┌─────────────────────────────────────┐
  │  形函数（面积坐标）：                 │
  │                                     │
  │  N₁ = (a₁ + b₁·x + c₁·y) / (2A)   │
  │  N₂ = (a₂ + b₂·x + c₂·y) / (2A)   │
  │  N₃ = (a₃ + b₃·x + c₃·y) / (2A)   │
  │                                     │
  │  A：三角形面积                       │
  │  N₁ + N₂ + N₃ = 1                  │
  └─────────────────────────────────────┘
```

其中系数：
```
  a₁ = x₂·y₃ - x₃·y₂    b₁ = y₂ - y₃    c₁ = x₃ - x₂
  a₂ = x₃·y₁ - x₁·y₃    b₂ = y₃ - y₁    c₂ = x₁ - x₃
  a₃ = x₁·y₂ - x₂·y₁    b₃ = y₁ - y₂    c₃ = x₂ - x₁
  
  2A = |x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
```

### 形函数的物理含义

```
    N₁ 在节点 1 处 = 1，在其他节点处 = 0

    N₁ 的分布：
    
    3
    │╲        N₁ = 1 (节点1)
    │  ╲       ↑
    │    ╲    ╱│╲
    │      ╲╱  │  ╲
    │     ╱ ╲  │    ╲
    │   ╱    ╲ │      ╲
    1═════════2        N₁ = 0 (节点2,3)
    
    N₁ 是从节点1到对边线性下降的平面
```

## 3.3 应变-位移矩阵 B

```
  应变与位移的关系：
  
  ε_x  = ∂u/∂x
  ε_y  = ∂v/∂y
  γ_xy = ∂u/∂y + ∂v/∂x
  
  写成矩阵形式：ε = B · u_e
  
  ┌────────────────────────────────────────────────────────┐
  │         1   ┌ b₁  0   b₂  0   b₃  0  ┐               │
  │  B = ───── │  0  c₁   0  c₂   0  c₃ │               │
  │       2A    └ c₁  b₁  c₂  b₂  c₃  b₃ ┘               │
  │                                                        │
  │  B 是 3×6 常数矩阵                                     │
  │  → CST 单元内应变为常数！（这也是名字的由来）           │
  └────────────────────────────────────────────────────────┘
```

## 3.4 单元刚度矩阵

```
  ┌──────────────────────────────────┐
  │                                  │
  │  K_e = t · A · B^T · D · B      │
  │                                  │
  │  t：单元厚度                     │
  │  A：三角形面积                   │
  │  B：应变-位移矩阵（3×6）        │
  │  D：弹性矩阵（3×3）             │
  │  K_e：6×6 矩阵                  │
  │                                  │
  └──────────────────────────────────┘
```

### 整个有限元流程图解

```
  节点坐标      材料参数      单元厚度
  (x_i, y_i)    (E, μ)         (t)
      │            │            │
      ↓            ↓            │
  计算 B 矩阵  计算 D 矩阵     │
  （3×6）      （3×3）         │
      │            │            │
      └─────┬──────┘            │
            ↓                   │
       K_e = t·A·B^T·D·B ←─────┘
       （6×6）
            │
            ↓ 按自由度组装
       K (总刚度矩阵)
            │
            ↓ 施加边界条件
       K·u = F → 求解 u
            │
            ↓
       ε = B·u_e → σ = D·ε
```

## 3.5 CST 单元的局限

```
  优点：                     缺点：
  ✓ 简单，容易编程            ✗ 单元内应变为常数
  ✓ 适合学习理解              ✗ 应力不连续（相邻单元突变）
  ✓ 可处理复杂形状            ✗ 精度低，需要大量单元
                              ✗ 弯曲问题效果很差
  
  改进方向：
  → 6 节点三角形（LST，二次插值，应变线性分布）
  → 4 节点四边形（双线性插值）
  → 8 节点四边形（二次插值，工程中最常用）
```

```
    单元精度对比：
    
    CST（3节点）     LST（6节点）      Q8（8节点四边形）
    
    3                3                 ●───●───●
    │╲              │╲                │       │
    │  ╲            ●  ●              ●       ●
    │    ╲          │    ╲            │       │
    1─────2         1──●──2           ●───●───●
    
    常应变           线性应变          双二次插值
    精度低           精度中            精度高（推荐）
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| N_i = (a_i + b_i·x + c_i·y)/(2A) | 三角形形函数 |
| ε = B · u_e | 应变-位移关系 |
| σ = D · ε | 应力-应变关系 |
| K_e = tA · B^T · D · B | CST 单元刚度矩阵 |
| 2A = x₁(y₂-y₃)+x₂(y₃-y₁)+x₃(y₁-y₂) | 三角形面积 |

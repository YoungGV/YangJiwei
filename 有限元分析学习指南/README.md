## 学习路线

```
  材料力学基础（应力、应变、胡克定律）
       │
       ↓
  有限元基本思想（离散化、插值、最小势能原理）
       │
       ↓
  一维有限元（杆/弹簧单元）← 先从这里入门！
       │
       ↓
  二维有限元（三角形、四边形单元）
       │
       ↓
  商业软件操作（ANSYS Workbench / Abaqus CAE）
       │
       ↓
  结合导师课题实践
```

## 推荐教材

- 曾攀《有限元分析基础教程》— 国内入门首选
- 王勖成《有限单元法》— 经典理论教材
- Logan《A First Course in the Finite Element Method》— 国际经典入门
- Fish & Belytschko《A First Course in Finite Elements》— 简洁清晰

# 第四章 等参单元与数值积分

## 4.1 等参单元的思想

物理空间中形状不规则的单元，映射到一个标准的"母单元"（自然坐标 ξ, η）进行计算。

```
    物理空间（x, y）          自然坐标（ξ, η）
    
    4───────────3             (-1,1)────────(1,1)
    │           │                │            │
    │  实际单元  │    ←映射→     │   母单元    │
    │           │                │  (-1~1)    │
    1───────────2             (-1,-1)───────(1,-1)
    
    任意四边形              标准正方形（-1 ≤ ξ,η ≤ 1）
```

### 等参的含义

```
  "等参" = 几何插值和位移插值使用相同的形函数
  
  几何映射：x = Σ N_i · x_i
           y = Σ N_i · y_i
  
  位移插值：u = Σ N_i · u_i
           v = Σ N_i · v_i
  
  同一组 N_i → "等参"
```

## 4.2 四节点四边形单元（Q4）

### 形函数

```
  ┌────────────────────────────────────────┐
  │  N₁ = ¼(1-ξ)(1-η)    节点1(-1,-1)    │
  │  N₂ = ¼(1+ξ)(1-η)    节点2(+1,-1)    │
  │  N₃ = ¼(1+ξ)(1+η)    节点3(+1,+1)    │
  │  N₄ = ¼(1-ξ)(1+η)    节点4(-1,+1)    │
  └────────────────────────────────────────┘
```

```
    母单元与形函数：
    
    4(-1,1)─────────3(1,1)
    │                │
    │    ξ →         │      每个 N_i 在对应节点 = 1
    │    ↓η          │      在其他节点 = 0
    │                │      Σ N_i = 1
    1(-1,-1)────────2(1,-1)
```

### 雅可比矩阵（Jacobian）

坐标变换的关键：

```
  ┌──────────────────────────────────┐
  │  ┌ ∂x/∂ξ   ∂y/∂ξ ┐             │
  │  │                │ = J（雅可比）│
  │  └ ∂x/∂η   ∂y/∂η ┘             │
  │                                  │
  │  ∂N_i/∂x = J⁻¹ · ∂N_i/∂ξ      │
  │  ∂N_i/∂y         ∂N_i/∂η      │
  │                                  │
  │  det(J) > 0 → 映射有效          │
  │  det(J) ≤ 0 → 单元畸变！        │
  └──────────────────────────────────┘
```

## 4.3 八节点四边形单元（Q8）

工程中**最常用**的二维单元。

```
    Q8 单元：
    
    4────7────3
    │         │       8 个节点
    8         6       16 个自由度
    │         │       二次插值
    1────5────2       精度高
    
    形函数（角节点，以节点1为例）：
    N₁ = ¼(1-ξ)(1-η)(-ξ-η-1)
    
    形函数（边中点，以节点5为例）：
    N₅ = ½(1-ξ²)(1-η)
```

## 4.4 数值积分——高斯积分

### 为什么需要数值积分

```
  K_e = ∫∫ B^T · D · B · |J| dξ dη
  
  等参变换后，被积函数变得复杂，
  通常无法解析积分 → 用数值积分
```

### 高斯积分（Gauss Quadrature）

```
  ┌───────────────────────────────────────────┐
  │  一维高斯积分：                             │
  │                                           │
  │  ∫₋₁¹ f(ξ) dξ ≈ Σ w_i · f(ξ_i)          │
  │                                           │
  │  ξ_i：高斯积分点（位置）                   │
  │  w_i：权重系数                             │
  │                                           │
  │  n 个积分点可以精确积分 2n-1 次多项式       │
  └───────────────────────────────────────────┘
```

### 常用高斯积分点

| 积分点数 n | 位置 ξ_i | 权重 w_i | 精度 |
|-----------|----------|---------|------|
| 1 | 0 | 2 | 1次 |
| 2 | ±1/√3 ≈ ±0.5774 | 1 | 3次 |
| 3 | 0, ±√(3/5) ≈ ±0.7746 | 8/9, 5/9 | 5次 |

```
    2点高斯积分的积分点位置（一维）：
    
    ──────●──────────────●──────
    -1   -1/√3     0    1/√3   1
          ξ₁              ξ₂
    
    ∫₋₁¹ f(ξ)dξ ≈ 1·f(-1/√3) + 1·f(1/√3)
```

### 二维高斯积分

```
  ∫∫ f(ξ,η) dξdη ≈ Σ_i Σ_j w_i · w_j · f(ξ_i, η_j)
  
  2×2 高斯积分（4个积分点）：
  
  (-1,1)────────────(1,1)
  │                  │
  │    ●        ●    │     ● = 积分点
  │                  │     位置：(±1/√3, ±1/√3)
  │    ●        ●    │     权重：全部为 1
  │                  │
  (-1,-1)───────────(1,-1)
```

### Q4 和 Q8 应使用的积分阶次

| 单元 | 推荐积分 | 精度 |
|------|---------|------|
| Q4 | 2×2 完全积分 | 标准 |
| Q4 | 1×1 减缩积分 | 防止剪切自锁，但可能出现沙漏模式 |
| Q8 | 3×3 完全积分 | 标准 |
| Q8 | 2×2 减缩积分 | 常用，效果好 |

## 4.5 单元选择指南（ANSYS/Abaqus 对照）

| 本章概念 | ANSYS 对应 | Abaqus 对应 |
|----------|-----------|-------------|
| Q4 完全积分 | PLANE182 | CPS4 / CPE4 |
| Q4 减缩积分 | — | CPS4R / CPE4R |
| Q8 完全积分 | PLANE183 | CPS8 / CPE8 |
| Q8 减缩积分 | — | CPS8R / CPE8R |
| CST 三角形 | PLANE182(退化) | CPS3 / CPE3 |

```
  Abaqus 单元命名规则：
  
  C PS 8 R
  │ │  │ │
  │ │  │ └── R = 减缩积分（Reduced）
  │ │  └──── 8 = 8节点
  │ └─────── PS = 平面应力（PE = 平面应变）
  └───────── C = 连续体单元
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| N_i = ¼(1±ξ)(1±η) | Q4 形函数 |
| K_e = ∫ B^T·D·B·\|J\| dξdη | 等参单元刚度矩阵 |
| ∫f(ξ)dξ ≈ Σw_i·f(ξ_i) | 高斯积分 |
| x = ΣN_i·x_i | 等参坐标映射 |

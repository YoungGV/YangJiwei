# 第二章 杆单元与弹簧单元（一维有限元入门）

从最简单的一维问题入门，理解有限元的完整流程。

## 2.1 弹簧单元

### 单元刚度矩阵

```
    弹簧单元（2 节点，每节点 1 自由度）：
    
    ●───/\/\/\/───●
    1    k         2
    u₁             u₂
    
    ┌────────────────────────┐
    │  单元刚度矩阵：          │
    │                        │
    │  K_e = ┌  k  -k ┐     │
    │        └ -k   k ┘     │
    │                        │
    │  F_e = K_e · u_e       │
    └────────────────────────┘
```

### 弹簧系统的组装

```
    两个弹簧串联：
    
    ●───/\/\/\/───●───/\/\/\/───●
    1    k₁        2    k₂       3
    u₁             u₂            u₃
    
    单元①（节点1-2）：        单元②（节点2-3）：
    K₁ = ┌ k₁  -k₁ ┐        K₂ = ┌ k₂  -k₂ ┐
         └-k₁   k₁ ┘             └-k₂   k₂ ┘
    
    组装到总体矩阵（3×3）：
    
         ┌  k₁    -k₁      0   ┐
    K =  │ -k₁   k₁+k₂   -k₂  │
         └   0    -k₂      k₂  ┘
    
    组装规则：单元矩阵按节点编号"对号入座"
```

### 完整求解示例

```
    已知：k₁ = 100 N/mm, k₂ = 200 N/mm
          节点1固定(u₁=0)，节点3施加 F₃ = 300 N
    
    ① 总体方程 K·u = F：
    ┌ 100   -100     0  ┐ ┌ u₁ ┐   ┌ F₁ ┐
    │-100    300   -200  │ │ u₂ │ = │  0 │
    └  0    -200    200  ┘ └ u₃ ┘   └ 300┘
    
    ② 施加边界条件 u₁ = 0（删去第1行第1列）：
    ┌ 300   -200 ┐ ┌ u₂ ┐   ┌  0  ┐
    │-200    200  │ │ u₃ │ = │ 300 │
    └            ┘ └    ┘   └     ┘
    
    ③ 求解：
    u₂ = 3 mm,  u₃ = 4.5 mm
    
    ④ 求支反力：
    F₁ = 100×0 - 100×3 = -300 N（向左）
    
    验证：ΣF = -300 + 0 + 300 = 0 ✓
```

## 2.2 杆单元（Truss Element）

### 一维杆单元刚度矩阵

```
    杆单元（2 节点，轴向自由度）：
    
    ●━━━━━━━━━━━━━━━━●
    1    E, A, l       2
    u₁                 u₂
    
    由 Δl = F·l/(EA) 推导：
    
    ┌──────────────────────────┐
    │          EA  ┌ 1  -1 ┐  │
    │  K_e = ─── │       │  │
    │          l   └-1   1 ┘  │
    └──────────────────────────┘
```

### 平面桁架单元（二维）

桁架杆件可以任意方向放置，需要**坐标变换**。

```
    局部坐标 → 全局坐标：
    
    y         2(x₂,y₂)
    ↑       ╱
    │     ╱  θ（杆件与x轴的夹角）
    │   ╱
    │ ╱
    ●──────────→ x
    1(x₁,y₁)
    
    l = cosθ,  m = sinθ（方向余弦）
```

```
  ┌──────────────────────────────────────────────────────┐
  │  平面桁架单元刚度矩阵（4×4，全局坐标）：               │
  │                                                      │
  │           EA  ┌  l²   lm   -l²  -lm ┐               │
  │  K_e =  ─── │  lm   m²   -lm  -m² │               │
  │           L   │ -l²  -lm    l²   lm │               │
  │               └ -lm  -m²    lm   m² ┘               │
  │                                                      │
  │  l = cosθ = (x₂-x₁)/L                               │
  │  m = sinθ = (y₂-y₁)/L                               │
  │  L = √[(x₂-x₁)² + (y₂-y₁)²]                        │
  └──────────────────────────────────────────────────────┘
```

### 桁架例题

```
    简单平面桁架：
    
         ●3
        ╱│╲
       ╱ │ ╲        F = 10 kN ↓（节点3）
      ╱  │  ╲
     ╱   │   ╲
    ●────┴────●
    1(固定)    2(滚动)
    
    EA = 200×10³ kN（各杆相同）
    
    ① 计算各杆长度和方向余弦
    ② 建立各杆 K_e（4×4）
    ③ 组装总刚度矩阵（6×6，3节点×2DOF）
    ④ 施加边界：u₁=v₁=0, v₂=0
    ⑤ 解方程 → 求节点位移
    ⑥ 反求各杆内力
```

## 2.3 组装过程详解

### 直接刚度法

```
  组装规则：按照自由度编号"对号入座"
  
  单元①连接节点 2 和 3：
  K_e 的第1行1列 → 总矩阵的第(2×2-1)行(2×2-1)列
  
  示意：
  
  单元刚度矩阵       总刚度矩阵
  ┌─────────┐       ┌─────────────────┐
  │ k₁₁ k₁₂│       │           │     │
  │ k₂₁ k₂₂│  ──→  │     k₁₁  │ k₁₂│  ← 放入对应位置
  └─────────┘       │     k₂₁  │ k₂₂│
                    │           │     │
                    └─────────────────┘
  
  重叠部分直接相加！
```

## 2.4 边界条件的处理

### 方法一：删行删列法

```
  已知 u₁ = 0：
  直接删去第1行和第1列，缩减方程组
  
  ┌ K₁₁  K₁₂  K₁₃ ┐ ┌ u₁ ┐   ┌ F₁ ┐
  │ K₂₁  K₂₂  K₂₃ │ │ u₂ │ = │ F₂ │
  └ K₃₁  K₃₂  K₃₃ ┘ └ u₃ ┘   └ F₃ ┘
  
  删去第1行第1列：
  ┌ K₂₂  K₂₃ ┐ ┌ u₂ ┐   ┌ F₂ ┐
  │ K₃₂  K₃₃ │ │ u₃ │ = │ F₃ │
  └           ┘ └    ┘   └    ┘
```

### 方法二：置大数法（编程常用）

```
  已知 u₁ = 0：
  将 K₁₁ 替换为很大的数 C（如 10²⁰）
  将 F₁ 替换为 C × 0 = 0
  
  ┌  C    K₁₂  K₁₃ ┐ ┌ u₁ ┐   ┌  0  ┐
  │ K₂₁  K₂₂  K₂₃ │ │ u₂ │ = │ F₂ │
  └ K₃₁  K₃₂  K₃₃ ┘ └ u₃ ┘   └ F₃ ┘
  
  由第1个方程：C·u₁ ≈ 0 → u₁ ≈ 0 ✓
```

## 2.5 从位移到应力

```
  求解流程：
  
  K·u = F  →  u（节点位移）
                │
                ↓
  应变：ε = B · u_e （B 是应变-位移矩阵）
                │
                ↓
  应力：σ = D · ε   （D 是弹性矩阵）
  
  对于杆单元：
  ε = (u₂ - u₁) / l
  σ = E · ε
  F_N = σ · A = EA(u₂ - u₁)/l
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| K_e = (EA/l)[1,-1;-1,1] | 杆单元刚度矩阵 |
| K = Σ K_e (组装) | 总体刚度矩阵 |
| K·u = F | 有限元基本方程 |
| σ = E·(u₂-u₁)/l | 杆单元应力 |

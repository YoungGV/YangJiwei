# 第一章 有限元基本概念

## 1.1 什么是有限元法

**有限元法（Finite Element Method, FEM）**：将连续体离散为有限个互相连接的小单元，在每个单元内用简单的近似函数描述物理量的分布，然后组装求解整体方程。

```
    连续体（精确但难以求解）：
    
    ┌─────────────────────┐
    │                     │
    │   连续体域 Ω        │  ← 偏微分方程，解析解很难求
    │                     │
    └─────────────────────┘
    
    有限元离散（近似但可求解）：
    
    ┌───┬───┬───┬───┬───┐
    │ ╲ │ ╱ │ ╲ │ ╱ │ ╲ │
    ├───┼───┼───┼───┼───┤  ← 分成许多小单元
    │ ╱ │ ╲ │ ╱ │ ╲ │ ╱ │    在每个单元内近似
    ├───┼───┼───┼───┼───┤    再组装成整体
    │ ╲ │ ╱ │ ╲ │ ╱ │ ╲ │
    └───┴───┴───┴───┴───┘
```

### 有限元的核心思想

```
  ┌──────────────────────────────────────────────┐
  │  "化整为零，积零为整"                          │
  │                                              │
  │  ① 离散化 ── 把大问题切成小单元               │
  │  ② 单元分析 ── 建立每个小单元的方程            │
  │  ③ 组装 ── 把所有单元方程拼在一起              │
  │  ④ 施加边界条件                               │
  │  ⑤ 求解线性方程组 → 得到节点位移              │
  │  ⑥ 后处理 → 计算应力、应变等                  │
  └──────────────────────────────────────────────┘
```

## 1.2 基本术语

```
    有限元模型的组成：
    
    ●─────●─────●
    │╲    │   ╱ │    ● 节点（Node）
    │  ╲  │  ╱  │    ─ 单元（Element）
    │    ╲│╱    │    △ 单元由节点连接
    ●─────●─────●
    │   ╱ │ ╲   │
    │  ╱  │  ╲  │
    │╱    │   ╲ │
    ●─────●─────●
```

| 术语 | 含义 |
|------|------|
| **节点（Node）** | 单元的顶点/边上的点，是求解的基本位置 |
| **单元（Element）** | 划分出的小区域（三角形、四边形、六面体等） |
| **自由度（DOF）** | 每个节点的独立未知量（如 u_x, u_y, u_z） |
| **形函数（Shape Function）** | 单元内部物理量的插值函数 |
| **刚度矩阵（Stiffness Matrix）** | 描述力与位移关系的矩阵 |
| **网格（Mesh）** | 由节点和单元组成的离散化模型 |

## 1.3 有限元的数学基础

### 从强形式到弱形式

以一维弹性杆为例：

```
  强形式（微分方程）：
  
  d/dx [EA · du/dx] + f(x) = 0    （在域内）
  
  边界条件：u(0) = 0（固定端）
           EA·du/dx|_{x=L} = F（自由端受力）

  问题：对于复杂形状/载荷，精确解很难求！
```

```
  弱形式（加权余量法 / 虚功原理）：
  
  ∫ EA · (du/dx) · (dv/dx) dx = ∫ f·v dx + F·v(L)
  
  v(x)：试函数（虚位移）
  
  弱形式 ← 等价于虚功原理！
  这正是有限元的数学出发点
```

### 最小势能原理

```
  ┌──────────────────────────────────────┐
  │  在所有满足位移边界条件的位移场中，   │
  │  真实位移场使总势能取最小值。         │
  │                                      │
  │  Π = U - W                           │
  │    = 应变能 - 外力功                  │
  │                                      │
  │  ∂Π/∂u_i = 0  →  K·u = F            │
  │                                      │
  │  这就是有限元方程的来源！             │
  └──────────────────────────────────────┘
```

## 1.4 刚度矩阵——有限元的核心

### 弹簧的力-位移关系

```
    弹簧（刚度 k）：
    
    ●───/\/\/\/───●
    1              2
    u₁             u₂
    F₁             F₂
    
    力-位移关系：
    F₁ = k(u₁ - u₂)
    F₂ = k(u₂ - u₁)
    
    写成矩阵形式：
    
    ┌ F₁ ┐   ┌  k  -k ┐ ┌ u₁ ┐
    │    │ = │        │ │    │
    └ F₂ ┘   └ -k   k ┘ └ u₂ ┘
    
    即 F = K · u
    
    K 就是刚度矩阵！
```

### 刚度矩阵的性质

```
  ┌──────────────────────────────────────┐
  │  K 的重要性质：                        │
  │                                      │
  │  ① 对称性：K = K^T                   │
  │  ② 奇异性：det(K) = 0（未施加边界前） │
  │  ③ 各行元素之和为零                   │
  │  ④ 正定或半正定                       │
  │  ⑤ 稀疏性（大部分元素为零）           │
  └──────────────────────────────────────┘
```

## 1.5 有限元求解流程

```
  ┌─────────────┐
  │  前处理      │
  │  ① 建立几何  │
  │  ② 定义材料  │
  │  ③ 划分网格  │──→ 节点、单元
  │  ④ 施加载荷  │
  │  ⑤ 施加约束  │
  └──────┬──────┘
         │
         ↓
  ┌─────────────┐
  │  求解        │
  │  ① 单元分析  │──→ 各单元 K_e
  │  ② 总体组装  │──→ 总刚度矩阵 K
  │  ③ 施加边界  │──→ 修改 K 和 F
  │  ④ 解方程    │──→ K·u = F → u
  └──────┬──────┘
         │
         ↓
  ┌─────────────┐
  │  后处理      │
  │  ① 位移云图  │
  │  ② 应力云图  │
  │  ③ 应变云图  │
  │  ④ 结果验证  │
  └─────────────┘
```

## 1.6 收敛性与误差

### h-收敛与 p-收敛

```
  h-收敛（加密网格）：
  
  粗网格          细网格          更细网格
  ┌────┬────┐    ┌──┬──┬──┬──┐  ┌─┬─┬─┬─┬─┬─┬─┬─┐
  │    │    │    │  │  │  │  │  │ │ │ │ │ │ │ │ │
  └────┴────┘    └──┴──┴──┴──┘  └─┴─┴─┴─┴─┴─┴─┴─┘
  误差大          误差较小        误差更小
  
  p-收敛（提高单元阶次）：
  
  线性单元        二次单元        三次单元
  ●────────●      ●────●────●    ●──●──●──●
  2 节点          3 节点          4 节点
  误差大          误差较小        误差更小
```

### 网格质量对结果的影响

```
  好的网格              差的网格
  
  ┌───┬───┬───┐         ┌───────┬─┐
  │   │   │   │         │       │ │
  ├───┼───┼───┤         │       │ │
  │   │   │   │         ├───┬───┘ │
  ├───┼───┼───┤         │   │     │
  │   │   │   │         │   │     │
  └───┴───┴───┘         └───┴─────┘
  
  单元形状规则            单元畸变严重
  长宽比接近 1:1          长宽比过大
  结果准确               结果不可靠
```

## 本章小结

```
  有限元法核心框架：
  
  物理问题（微分方程）
       │
       ↓  弱形式 / 最小势能原理
  
  K · u = F  （有限元基本方程）
  
  K：刚度矩阵（由材料、几何、单元类型决定）
  u：节点位移向量（待求未知量）
  F：节点力向量（外载荷等效到节点）
  
  求出 u 后 → 应变 ε = B·u → 应力 σ = D·ε
```

# 第五章 有限元建模实践（ANSYS / Abaqus）

## 5.1 ANSYS Workbench 操作流程

```
  ANSYS Workbench 标准流程：
  
  ┌──────────────┐
  │ Engineering  │
  │    Data      │ ← ① 定义材料（E, μ, σ_s 等）
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │   Geometry   │ ← ② 建立或导入几何模型
  │ (SpaceClaim/ │    支持 STEP/IGES/Parasolid
  │  DesignMod.) │
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │    Model     │ ← ③ 划分网格
  │   (Mesh)     │    设置网格尺寸、单元类型
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │    Setup     │ ← ④ 施加载荷和边界条件
  │  (Loads &    │    力、压力、位移约束等
  │   BC)        │
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │   Solution   │ ← ⑤ 求解
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │   Results    │ ← ⑥ 后处理（查看云图）
  │              │    位移、应力、应变
  └──────────────┘
```

## 5.2 Abaqus CAE 操作流程

```
  Abaqus CAE 模块化流程：
  
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  Part    │→│ Property │→│ Assembly │
  │ 建立零件 │  │ 材料&截面 │  │ 装配     │
  └──────────┘  └──────────┘  └──────────┘
       ↓
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  Step    │→│   Load   │→│   Mesh   │
  │ 分析步   │  │ 载荷&边界│  │ 网格划分 │
  └──────────┘  └──────────┘  └──────────┘
       ↓
  ┌──────────┐  ┌──────────────────────┐
  │   Job    │→│  Visualization      │
  │ 提交计算 │  │  后处理（ODB结果）    │
  └──────────┘  └──────────────────────┘
```

### Abaqus 各模块详解

| 模块 | 操作 | 要点 |
|------|------|------|
| Part | 创建/导入几何 | 确定2D/3D、变形体/刚体 |
| Property | 材料+截面 | Elastic → E, μ；截面赋予单元 |
| Assembly | 装配 | Instance → Independent/Dependent |
| Step | 分析步 | Static, General 最常用 |
| Load | 载荷+边界条件 | Concentrated Force, Pressure, Encastre |
| Mesh | 网格划分 | 种子大小、单元类型、算法 |
| Job | 提交计算 | Monitor 查看收敛 |

## 5.3 网格划分要点

### 网格尺寸选择

```
  原则：应力梯度大的地方网格要细

  ┌───────────────────────────────────┐
  │          ←── 载荷                  │
  │    ┌──┐                           │
  │    │  │  ← 应力集中处             │
  │    │  │    网格要加密！             │
  │    │  ├──────────────────         │
  │    │  │▓▓▓▓▓                      │
  │    │  │▓▓▓细密网格                 │
  │    │  ├──────────────────         │
  │    │  │  ← 圆角/缺口               │
  │    └──┘                           │
  │    稀疏网格即可 ──→                │
  │                                   │
  └───────────────────────────────────┘
```

### 网格质量检查

```
  常见网格质量指标：
  
  ① 长宽比（Aspect Ratio）
     理想值 < 3:1，最大不超过 10:1
     
     好:  ┌──┐     差: ┌──────────┐
          │  │         │          │
          └──┘         └──────────┘
     1:1              10:1
  
  ② 雅可比比率（Jacobian Ratio）
     理想值 = 1，不应 < 0
     
  ③ 翘曲度（Warping）
     3D 单元面的非平面度
  
  ④ 偏斜度（Skewness）
     偏离理想形状的程度
     理想值 = 0，最大不超过 0.95
```

### 网格收敛性验证

```
  必须做网格收敛性研究！
  
  步骤：
  ① 粗网格求解 → 记录关键点的应力 σ₁
  ② 加密网格   → 记录 σ₂
  ③ 再加密     → 记录 σ₃
  ④ 画收敛曲线
  
  应力
  ↑
  │              ●───●───● 收敛了！
  │           ●╱
  │        ●╱
  │     ●╱
  │  ●╱
  │●╱
  └────────────────────→ 单元数
  
  当加密后结果变化 < 5%，认为收敛
```

## 5.4 边界条件与载荷

### 常用边界条件

```
  固定约束（Encastre / Fixed Support）：
  ▌═══════    u = v = w = 0, θ_x = θ_y = θ_z = 0
  
  铰支座（Pin / Simply Supported）：
  △═══════    u = v = 0（允许转动）
  
  滚动支座（Roller）：
  ○═══════    v = 0（一个方向约束）
  
  对称约束（Symmetry）：
  ═══╫═══    法向位移 = 0，切向自由
              用于减少一半模型！
```

### 利用对称性减小模型

```
    原始模型（全模型）：           利用对称性（1/4模型）：
    
    ┌─────────────────┐          ┌──────────┐
    │                 │          │          │
    │        ↓F       │          │    ↓F/4  │
    │    ┌───────┐    │          │   ┌────  ║ 对称面
    │    │ 孔洞  │    │    →     │   │ 孔  ║
    │    └───────┘    │          │   └────  ║
    │                 │          │          │
    └─────────────────┘          └══════════┘
                                  对称面
    
    节省 3/4 的计算量！
```

### 载荷类型

| ANSYS | Abaqus | 说明 |
|-------|--------|------|
| Force | Concentrated Force | 集中力 |
| Pressure | Pressure | 面压力 |
| Remote Force | — | 远端力 |
| Moment | Moment | 力矩 |
| Thermal Condition | Predefined Field (Temperature) | 温度载荷 |
| Acceleration | Gravity | 重力/加速度 |

## 5.5 结果解读

### 应力云图读取

```
  后处理中常看的结果：
  
  ┌──────────────────────────────────────────┐
  │  Von Mises Stress（等效应力）             │
  │  → 判断是否屈服：σ_VM < σ_s ？          │
  │  → 工程中最常用的应力指标                │
  │                                          │
  │  Principal Stress（主应力）               │
  │  → σ₁（最大主应力）、σ₃（最小主应力）   │
  │  → 脆性材料看 σ₁                         │
  │                                          │
  │  Displacement（位移）                     │
  │  → 判断变形是否超限                      │
  │  → 确认变形模式是否合理                  │
  │                                          │
  │  Reaction Force（支反力）                 │
  │  → 验证平衡（合力应 ≈ 0）               │
  └──────────────────────────────────────────┘
```

### 结果验证清单

```
  ✓ 位移方向和大小是否合理？
  ✓ 变形模式是否符合直觉？
  ✓ 支反力之和是否等于外载荷？
  ✓ 应力是否有奇异值（通常在约束点附近）？
  ✓ 网格收敛性是否满足？
  ✓ 能否与简单手算结果对比？
```

## 5.6 初学者常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 未检查单位一致性 | 结果差几个量级 | 统一用 mm-N-MPa 或 m-N-Pa |
| 约束不足（刚体运动） | 求解失败/奇异 | 确保消除所有刚体位移 |
| 过约束 | 应力偏小 | 只加必要的约束 |
| 网格过粗 | 结果不准 | 做网格收敛性研究 |
| 忽略应力集中 | 局部应力低估 | 在尖角处加密网格 |
| 线性分析用于大变形 | 结果失真 | 开启几何非线性 |

### ANSYS 常用单位制

| 系统 | 长度 | 力 | 应力 | 质量 |
|------|------|-----|------|------|
| SI | m | N | Pa | kg |
| **工程常用** | **mm** | **N** | **MPa** | **tonne (10³kg)** |
| 英制 | in | lbf | psi | slug |

## 本章实践建议

```
  入门练习顺序：
  
  ① 悬臂梁端部集中力 ── 与理论解对比
  ② 简支梁均布载荷 ── 学习网格收敛
  ③ 带孔板拉伸 ── 学习应力集中
  ④ 接触问题 ── 螺栓连接
  ⑤ 热应力分析 ── 热-结构耦合
  ⑥ 模态分析 ── 固有频率
  
  每个练习都先手算，再建模，最后对比结果！
```

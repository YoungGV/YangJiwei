# 有限元分析公式速查表

## 一、有限元基本方程

| 公式 | 说明 |
|------|------|
| **K · u = F** | 有限元基本方程 |
| ε = B · u_e | 应变-位移关系 |
| σ = D · ε | 应力-应变关系（本构） |
| K_e = ∫ B^T · D · B dV | 单元刚度矩阵（一般形式） |

## 二、一维单元

| 单元 | 刚度矩阵 K_e |
|------|-------------|
| 弹簧 (k) | [k, -k; -k, k] |
| 杆 (EA, l) | (EA/l)[1, -1; -1, 1] |
| 梁 (EI, l) | 4×4 矩阵（见梁单元理论） |

### 杆单元应力
```
σ = E · (u₂ - u₁) / l
```

## 三、平面问题弹性矩阵 D

### 平面应力
```
       E      ┌ 1   μ     0      ┐
D = ──────── │ μ   1     0      │
    1 - μ²   └ 0   0   (1-μ)/2  ┘
```

### 平面应变
```
      E(1-μ)         ┌  1       μ/(1-μ)     0              ┐
D = ─────────────── │ μ/(1-μ)   1          0              │
    (1+μ)(1-2μ)     └  0        0         (1-2μ)/[2(1-μ)] ┘
```

## 四、CST 三角形单元

| 公式 | 说明 |
|------|------|
| 2A = x₁(y₂-y₃)+x₂(y₃-y₁)+x₃(y₁-y₂) | 面积 |
| N_i = (a_i + b_i·x + c_i·y) / (2A) | 形函数 |
| K_e = t·A · B^T · D · B | 刚度矩阵 |

### B 矩阵
```
       1   ┌ b₁  0   b₂  0   b₃  0  ┐
B = ───── │  0  c₁   0  c₂   0  c₃ │
     2A    └ c₁  b₁  c₂  b₂  c₃  b₃ ┘
```

### 系数
```
b₁=y₂-y₃  b₂=y₃-y₁  b₃=y₁-y₂
c₁=x₃-x₂  c₂=x₁-x₃  c₃=x₂-x₁
```

## 五、等参单元形函数

### Q4（四节点四边形）
```
N₁ = ¼(1-ξ)(1-η)   N₂ = ¼(1+ξ)(1-η)
N₃ = ¼(1+ξ)(1+η)   N₄ = ¼(1-ξ)(1+η)
```

### 等参变换
```
x = Σ N_i · x_i     y = Σ N_i · y_i
K_e = ∫∫ B^T · D · B · |J| dξ dη
```

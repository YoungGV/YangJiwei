# 第三章 剪切与扭转

## 3.1 剪切的概念

**剪切**：外力作用线与杆件轴线垂直，且力的作用面相距很近，使杆件沿受力面发生相对滑移。

```
    单剪切（如铆钉连接）：
    
    ┌─────────┐  ← F
    │         ║
    │    铆钉  ║
    │         ║
    └─────────┘
    ┌─────────┐  → F（固定）
    │         ║
    └─────────┘
              ↕ 剪切面

    双剪切（如叉耳连接）：
    
    ┌──────┐         ┌──────┐
    │      ║         ║      │  → F/2（上板固定）
    │      ║─────────║      │
    │      ║    ←F   ║      │  ← F（中间板受力）
    │      ║─────────║      │
    │      ║         ║      │  → F/2（下板固定）
    └──────┘         └──────┘
           ↕ 剪切面1  ↕ 剪切面2
```

### 剪切的实用计算（工程方法）

假设剪应力在剪切面上**均匀分布**：

```
  ┌─────────────────────────┐
  │        F_Q              │
  │  τ = ──────             │
  │         A               │
  │                         │
  │  F_Q：剪切面上的剪力     │
  │  A ：剪切面面积          │
  └─────────────────────────┘
```

**强度条件**：τ ≤ [τ]

### 挤压应力

连接件（铆钉、螺栓、销钉）与被连接件接触面上的压应力：

```
  ┌───────────────────────────┐
  │         F                 │
  │  σ_bs = ──────            │
  │         A_bs              │
  │                           │
  │  A_bs = d · t             │
  │  d：铆钉（销钉）直径       │
  │  t：被连接件中较薄者的厚度  │
  └───────────────────────────┘
```

```
    挤压面示意：
    
    ┌─────────────┐
    │             │
    │    ╭───╮    │  ← 铆钉截面
    │    │   │    │
    │    ╰───╯    │     挤压面 = 直径 × 厚度
    │      d      │     A_bs = d × t
    │             │
    └──────┬──────┘
           t（板厚）
```

**强度条件**：σ_bs ≤ [σ_bs]

## 3.2 扭转的概念

**扭转**：杆件受到大小相等、方向相反的力偶作用，绕轴线发生扭转变形。

```
    扭转示意：
    
         ⟳ T（扭矩）
         ║
    ═════╬═════════════════════
         ║                    ║
                              ⟲ T
    
    变形特征：各截面绕轴线发生相对转动
```

典型工程实例：传动轴、螺丝刀、弹簧等。

## 3.3 外力偶矩的计算

传动轴传递功率时的外力偶矩：

```
  ┌─────────────────────────┐
  │          P               │
  │  T = 9549 ───            │
  │          n               │
  │                          │
  │  T：扭矩（N·m）          │
  │  P：功率（kW）           │
  │  n：转速（r/min）        │
  └─────────────────────────┘
```

## 3.4 扭矩与扭矩图

### 用截面法求扭矩

```
    传动轴受力图：
    
    ⟳T₁   ⟲T₂        ⟳T₃
    ╪══════╪══════════╪════════▌
    A      B          C        D
    
    平衡条件：T₁ - T₂ + T₃ = 0
    
    各段扭矩（截面法）：
    段 AB：T(AB) = T₁
    段 BC：T(BC) = T₁ - T₂
    段 CD：T(CD) = T₁ - T₂ + T₃ = 0
```

### 扭矩图

```
    扭矩图示例：
    
    T
    ↑   T₁
    │  ┌────┐
    │  │    │
    ├──┘    │  T₁-T₂
    │       └──────┐
    │              │
    └──────────────┘──────→ x
    A      B       C      D
```

## 3.5 圆轴扭转时的应力

### 剪应力分布

**平面假设**：扭转时横截面保持平面，仅绕轴线转动。

```
    圆截面上剪应力分布：
    
         ╱───────╲
        ╱   → →   ╲
       │  ↑     ↓   │    剪应力 τ 沿半径
       │  ↑  ·  ↓   │    线性分布：
       │  ↑     ↓   │    
        ╲   ← ←   ╱     圆心处 τ = 0
         ╲───────╱       边缘处 τ = τ_max
    
    沿径向的分布：
    
    τ_max ────────────→●
                      ╱│
                    ╱  │
                  ╱    │
                ╱      │
    ─────────·─────────│──→ ρ
    0      圆心     R（半径）
```

### 扭转剪应力公式

```
  ┌──────────────────────────────┐
  │        T · ρ                 │
  │  τ = ────────     （任意点）  │
  │        I_p                   │
  │                              │
  │        T                     │
  │  τ_max = ────   （最外边缘）  │
  │        W_t                   │
  │                              │
  │  I_p：极惯性矩              │
  │  W_t：抗扭截面系数           │
  │  ρ ：该点到圆心的距离        │
  └──────────────────────────────┘
```

### 截面几何量

| 截面 | 极惯性矩 I_p | 抗扭截面系数 W_t |
|------|-------------|----------------|
| 实心圆 (直径 d) | πd⁴/32 | πd³/16 |
| 空心圆 (外径 D, 内径 d, α=d/D) | πD⁴(1-α⁴)/32 | πD³(1-α⁴)/16 |

```
    实心圆截面：           空心圆截面：
    
      ╭───────╮            ╭───────╮
     ╱         ╲          ╱ ╭───╮   ╲
    │           │        │  │   │    │
    │     ·     │        │  │ · │    │
    │    d      │        │  │   │    │
     ╲         ╱          ╲ ╰───╯   ╱
      ╰───────╯            ╰───────╯
                            D    d
                           α = d/D
```

## 3.6 扭转强度条件与刚度条件

### 强度条件

```
  ┌─────────────────────────────────┐
  │       T_max                     │
  │  τ_max = ────── ≤ [τ]          │
  │        W_t                      │
  │                                 │
  │  三种应用：                      │
  │  ① 校核强度：τ_max ≤ [τ] ？     │
  │  ② 设计截面：W_t ≥ T_max / [τ] │
  │  ③ 许可扭矩：T ≤ [τ] · W_t     │
  └─────────────────────────────────┘
```

### 刚度条件

单位长度扭转角不得超过许用值：

```
  ┌─────────────────────────────────┐
  │         T                       │
  │  φ' = ────── ≤ [φ']             │
  │       G·I_p                     │
  │                                 │
  │  φ'：单位长度扭转角（rad/m）     │
  │  G ：剪切模量                    │
  │  G·I_p：抗扭刚度                 │
  │  [φ']：许用扭转角                │
  │       （传动轴常取 0.5~1°/m）    │
  └─────────────────────────────────┘
```

### 例题：传动轴设计

```
    已知：传递功率 P = 10 kW，转速 n = 500 r/min
          材料 [τ] = 40 MPa
    
    求：所需实心轴最小直径

    解：
    ① 求扭矩：T = 9549 × P/n = 9549 × 10/500 = 191 N·m

    ② 由强度条件：W_t ≥ T/[τ] = 191×10³/(40) = 4775 mm³

    ③ 由 W_t = πd³/16：
       d³ ≥ 16×4775/π = 24,319
       d ≥ 29.0 mm
    
    取标准直径 d = 30 mm ✓
```

## 3.7 剪应力互等定理

```
  ┌──────┐
  │  ↓τ  │
  │      │
  │τ→  ←τ│    在相互垂直的两个面上，
  │      │    剪应力大小相等，方向共同
  │  ↑τ  │    指向或背离交线（棱边）。
  └──────┘
  
  即：τ_xy = τ_yx
```

这是一个非常重要的基本定理，后续学习应力状态时会反复用到。

## 本章公式总结

| 公式 | 用途 |
|------|------|
| τ = F_Q / A | 剪切应力（工程方法） |
| σ_bs = F / A_bs | 挤压应力 |
| T = 9549P/n | 传动轴扭矩 |
| τ = Tρ / I_p | 任意点剪应力 |
| τ_max = T / W_t | 最大剪应力 |
| φ' = T / (GI_p) | 单位长度扭转角 |

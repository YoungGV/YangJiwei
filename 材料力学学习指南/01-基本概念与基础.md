# 第一章 基本概念与基础

## 1.1 材料力学的研究对象

材料力学研究**杆件**（长度远大于截面尺寸的构件）在外力作用下的**变形**和**破坏**规律。

核心任务是解决三个问题：
- **强度**（Strength）：构件是否会断裂？
- **刚度**（Stiffness）：构件变形是否超出允许范围？
- **稳定性**（Stability）：细长压杆是否会失稳弯曲？

## 1.2 外力与内力

### 外力分类

```
 外力 ┬─ 载荷（主动力）┬─ 集中力 F（单位：N）
      │               ├─ 分布力 q（单位：N/m）
      │               └─ 力偶矩 M（单位：N·m）
      │
      └─ 约束反力（被动力）── 由支座提供
```

### 内力与截面法

**内力**：构件内部各部分之间的相互作用力。

**截面法**是求内力的基本方法，三步走：

```
 ┌─────────────────────────────────────┐
 │  截面法三步骤：                      │
 │                                     │
 │  ① 截开 ── 在需要求内力的截面处      │
 │            假想地将杆件切开           │
 │                                     │
 │  ② 代替 ── 用内力代替被切掉部分      │
 │            对保留部分的作用           │
 │                                     │
 │  ③ 平衡 ── 对保留部分列平衡方程      │
 │            求解内力                  │
 └─────────────────────────────────────┘
```

**截面法图示**：

```
     原始杆件：
     ══════════════════════
     ↑A                   ↓B
     Ra                   Rb

     在 m-m 截面处截开：
     
     ═══════╫══════════════
     ↑A     ║m            ↓B
     Ra     ║              Rb
            ║
     取左段：
     ═══════╫→ FN（轴力）
     ↑A     ║↓ FQ（剪力）
     Ra     ║⟳ M（弯矩）
```

### 四种基本内力

| 内力 | 符号 | 方向 | 对应变形 |
|------|------|------|----------|
| 轴力 | F_N | 沿轴线方向 | 拉伸/压缩 |
| 剪力 | F_Q | 垂直于轴线 | 剪切 |
| 弯矩 | M | 使杆弯曲 | 弯曲 |
| 扭矩 | T | 绕轴线方向 | 扭转 |

## 1.3 应力（Stress）

### 定义

应力是**单位面积上的内力**，描述的是材料内部受力的"强烈程度"。

```
         ΔF
σ = lim ────
   ΔA→0  ΔA
```

### 正应力与剪应力

```
    截面示意图：
    
    ┌────────────────┐
    │    ↑ ↑ ↑ ↑     │  ← 正应力 σ（垂直于截面）
    │                │
    │  → → → → →     │  ← 剪应力 τ（平行于截面）
    │                │
    └────────────────┘
```

| 类型 | 符号 | 方向 | 单位 |
|------|------|------|------|
| 正应力 (Normal stress) | σ | 垂直于截面 | Pa = N/m²，工程常用 MPa |
| 剪应力 (Shear stress) | τ | 平行于截面 | Pa = N/m²，工程常用 MPa |

> **单位换算**：1 MPa = 10⁶ Pa = 1 N/mm²

## 1.4 应变（Strain）

### 线应变（正应变）

描述构件沿某方向的**伸长或缩短的程度**：

```
        Δl     l - l₀
  ε = ──── = ────────
        l₀       l₀
```

```
    变形前：  |←───── l₀ ─────→|
              ══════════════════
    
    变形后：  |←──────── l ──────────→|
              ═══════════════════════════
                                    ↑
                              Δl = l - l₀
```

- ε > 0：伸长（拉伸）
- ε < 0：缩短（压缩）
- ε 是无量纲量，常用 10⁻⁶ (微应变 με)

### 角应变（剪应变）

描述**直角的改变量**：

```
    变形前：            变形后：
    ┌──────            ╱──────
    │                 ╱ ↙ γ（角应变）
    │                ╱
    │               ╱
```

γ（gamma）= 直角的改变量（弧度），γ > 0 表示直角减小。

## 1.5 胡克定律（Hooke's Law）

### 一维胡克定律

在弹性范围内，应力与应变成**线性关系**：

```
  ┌─────────────────────┐
  │                     │
  │   σ = E · ε         │  ← 应力-应变关系
  │                     │
  │   τ = G · γ         │  ← 剪应力-剪应变关系
  │                     │
  └─────────────────────┘
```

| 常数 | 名称 | 含义 | 常见值 |
|------|------|------|--------|
| E | 弹性模量 (Young's modulus) | 材料抵抗拉压变形的能力 | 钢：210 GPa，铝：70 GPa |
| G | 剪切模量 (Shear modulus) | 材料抵抗剪切变形的能力 | 钢：80 GPa |
| μ (ν) | 泊松比 (Poisson's ratio) | 横向应变与纵向应变之比 | 钢：0.3，橡胶：≈0.5 |

### 三个弹性常数的关系

```
         E
  G = ────────
      2(1 + μ)
```

## 1.6 材料的力学性能（拉伸试验）

### 应力-应变曲线（低碳钢）

```
  σ
  ↑        σb ●─────╲
  │           ╱       ╲  (强化阶段→颈缩→断裂)
  │    σs ●──╱         ╲
  │        │╱            ● 断裂
  │   σp ●─┤ (屈服阶段，应力几乎不变)
  │       ╱│
  │      ╱ │
  │     ╱  │ ← 弹性阶段（线性）
  │    ╱   │
  │   ╱    │
  │  ╱     │
  │ ╱      │
  │╱       │
  └────────┴──────────────→ ε
  O
```

### 四个重要的应力值

| 符号 | 名称 | 含义 |
|------|------|------|
| σ_p | 比例极限 | 应力-应变保持线性关系的最大应力 |
| σ_e | 弹性极限 | 卸载后变形能完全恢复的最大应力 |
| σ_s | 屈服极限 | 材料开始显著塑性变形的应力（**设计的主要依据**） |
| σ_b | 强度极限 | 材料能承受的最大应力 |

### 塑性与脆性材料对比

```
  σ                           σ
  ↑     塑性材料               ↑     脆性材料
  │     (如低碳钢)              │     (如铸铁)
  │      ╱──╲                  │         ╱● 断裂
  │     ╱    ╲                 │        ╱
  │  ──╱      ╲                │       ╱
  │   ╱        ╲               │      ╱
  │  ╱          ● 断裂         │     ╱
  │ ╱  延伸率大                │    ╱  延伸率小
  │╱                           │   ╱
  └─────────→ ε                │  ╱
                               │ ╱
                               │╱
                               └──────→ ε
  
  特点：有屈服，断前变形大       特点：无屈服，突然断裂
  危险应力：σ_s                 危险应力：σ_b
```

### 许用应力与安全系数

```
             σ_s
  [σ] = ─────────    （塑性材料）
              n_s

             σ_b
  [σ] = ─────────    （脆性材料）
              n_b
```

| 参数 | 含义 | 典型值 |
|------|------|--------|
| [σ] | 许用应力 | 根据材料和安全系数确定 |
| n_s | 屈服安全系数 | 1.5 ~ 2.0 |
| n_b | 强度安全系数 | 2.0 ~ 3.5 |

## 1.7 基本假设

材料力学建立在以下假设之上（理解这些假设对有限元分析非常重要）：

| 假设 | 含义 | 何时不成立 |
|------|------|-----------|
| **连续性假设** | 材料连续分布，无空隙 | 泡沫、多孔材料 |
| **均匀性假设** | 各处力学性质相同 | 复合材料、焊接接头 |
| **各向同性假设** | 各方向力学性质相同 | 木材、纤维增强材料 |
| **小变形假设** | 变形远小于构件尺寸 | 橡胶件、薄膜结构 |

> **与仿真的联系**：在 ANSYS/Abaqus 中设置材料属性时，选择 "Linear Elastic → Isotropic" 就是在使用上述假设。如果材料不满足这些假设，就需要选择非线性、各向异性等更复杂的模型。


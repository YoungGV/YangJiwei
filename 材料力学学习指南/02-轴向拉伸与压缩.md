# 第二章 轴向拉伸与压缩

## 2.1 轴向拉压的概念

当外力沿杆件轴线方向作用，且作用线通过截面形心时，杆件发生**轴向拉伸或压缩**。

```
    拉伸：
    ←── F  ═══════════════════  F ──→
           ←─── 杆被拉长 ───→

    压缩：
    ──→ F  ═══════════════════  F ←──
           →─── 杆被压短 ───←
```

实际工程中的典型拉压杆：桥梁桁架杆件、液压缸活塞杆、螺栓等。

## 2.2 轴力与轴力图

### 用截面法求轴力

对截面左侧（或右侧）取隔离体，由平衡方程 ΣF_x = 0 求解：

**例题**：阶梯杆受力如图，求各段轴力。

```
    ←─ 2F    F ─→        ←─ F
    ════╪════╪═══════════╪════▌
    A   B    C           D    固定端
    
    段 AB：取 A 点左侧截面
    ΣFx = 0:  F_N1 - 2F = 0  →  F_N1 = 2F（拉）
    
    段 BC：取 B 点左侧截面
    ΣFx = 0:  F_N2 - 2F + F = 0  →  F_N2 = F（拉）
    
    段 CD：取 C 点左侧截面
    ΣFx = 0:  F_N3 - 2F + F - F = 0  →  F_N3 = 0
```

### 轴力图

将各段轴力画成沿杆件长度方向的图形：

```
    载荷图：
    ←─ 2F    F ─→        ←─ F
    ════╪════╪═══════════╪════▌
    A   B    C           D

    轴力图 F_N：
         2F ┌────┐
            │    │ F
            │    └────┐
    ────────┘         │────── 0 基线
    A   B    C        D

    (+) 拉力在基线上方
    (-) 压力在基线下方
```

> **画图规则**：轴力为正（拉）画在基线上方，为负（压）画在基线下方。集中力作用处轴力突变。

## 2.3 拉压杆的应力

### 横截面上的正应力

```
  ┌───────────────────────┐
  │         F_N           │
  │  σ = ──────           │
  │          A            │
  │                       │
  │  σ：正应力（MPa）      │
  │  F_N：轴力（N）        │
  │  A：横截面面积（mm²）   │
  └───────────────────────┘
```

```
    截面上应力分布（均匀分布）：
    
    ┌──────────────┐
    │ → → → → → → │  σ = F_N / A
    │ → → → → → → │  各点应力相等
    │ → → → → → → │
    │ → → → → → → │
    └──────────────┘
    
    这是在满足"圣维南原理"的前提下
    （远离力作用点的区域）
```

### 斜截面上的应力

在与轴线成 α 角的斜截面上：

```
                  ╱│
                ╱  │
              ╱ α  │
            ╱      │     σ_α = σ · cos²α
          ╱────────│
            ╱  α          τ_α = σ/2 · sin2α
          ╱
```

```
  σ_α = σ · cos²α        ← 斜截面正应力

  τ_α = (σ/2) · sin 2α   ← 斜截面剪应力
```

**重要结论**：
- α = 0° 时，σ_α 最大 = σ，τ_α = 0（横截面）
- α = 45° 时，τ_α 最大 = σ/2（最大剪应力截面）
- α = 90° 时，σ_α = 0，τ_α = 0（纵截面）

## 2.4 拉压杆的变形

### 轴向变形公式

```
  ┌───────────────────────────┐
  │        F_N · l            │
  │  Δl = ────────            │
  │        E · A              │
  │                           │
  │  Δl：伸长量（mm）          │
  │  F_N：轴力（N）            │
  │  l ：杆件长度（mm）        │
  │  E ：弹性模量（MPa）       │
  │  A ：截面面积（mm²）       │
  └───────────────────────────┘
```

其中 EA 称为**抗拉（压）刚度**。

### 多段杆的变形

各段轴力、截面积或材料不同时，总变形等于各段变形之和：

```
           n    F_Ni · li
  Δl = Σ  ─────────────
          i=1   Ei · Ai
```

### 例题：求阶梯杆总变形

```
    ←─ 20kN           40kN ─→
    ═══════╪═══════════╪══════▌
    A      B           C      D（固定端）
    ├─200─┤├───300────┤├─200─┤  (mm)
    
    截面积：A_AB = A_CD = 200 mm²
            A_BC = 400 mm²
    材料：钢，E = 200 GPa = 200×10³ MPa

    先求各段轴力：
    F_N(AB) = -20 kN = -20×10³ N（压）
    F_N(BC) = -20 + 40 = 20 kN = 20×10³ N（拉）
    F_N(CD) = 由平衡求得

    各段变形：
    Δl_AB = F_N(AB)·l_AB / (E·A_AB) = (-20×10³×200)/(200×10³×200)
          = -0.1 mm（缩短）

    Δl_BC = F_N(BC)·l_BC / (E·A_BC) = (20×10³×300)/(200×10³×400)
          = 0.075 mm（伸长）

    总变形 = Σ各段变形
```

## 2.5 拉压杆的强度条件

### 强度校核公式

```
  ┌─────────────────────────────────┐
  │        F_N                      │
  │  σ = ────── ≤ [σ]              │
  │         A                       │
  │                                 │
  │  三种应用：                      │
  │  ① 校核强度：σ_max ≤ [σ] ？     │
  │  ② 选择截面：A ≥ F_N / [σ]     │
  │  ③ 确定许可载荷：F ≤ [σ]·A      │
  └─────────────────────────────────┘
```

### 例题：强度校核

```
    某钢杆：截面积 A = 500 mm²，轴力 F_N = 80 kN
    材料许用应力 [σ] = 170 MPa
    
    解：σ = F_N / A = 80×10³ / 500 = 160 MPa
    
    因为 σ = 160 MPa < [σ] = 170 MPa
    
    ∴ 强度满足要求 ✓
```

## 2.6 拉压超静定问题

当**平衡方程的数量 < 未知力的数量**时，问题是**超静定**的。

### 解题思路

```
  超静定求解三步法：
  
  ┌──────────┐   ┌──────────┐   ┌──────────┐
  │ 平衡方程  │ + │ 变形协调  │ + │ 物理方程  │ = 求解
  │（静力学） │   │（几何关系）│   │（胡克定律）│
  └──────────┘   └──────────┘   └──────────┘
       ↑               ↑               ↑
   ΣF = 0         变形约束         σ = Eε
   ΣM = 0         几何约束        Δl = FNl/EA
```

### 典型例题：两端固定杆

```
    ▌═══════════╪═══════════▌
    A     a     │     b     B
    ↑           F           ↑
    R_A                     R_B
    
    已知：截面积 A，弹性模量 E，力 F
    
    ① 平衡方程：R_A + R_B = F  ← 1个方程，2个未知数 → 超静定
    
    ② 变形协调：两端固定 → 总变形 = 0
       Δl_AC + Δl_CB = 0
    
    ③ 物理方程（胡克定律）：
       R_A·a/(EA) - R_B·b/(EA) = 0
       → R_A·a = R_B·b
    
    联立 ① 和 ③：
       R_A = Fb/(a+b)
       R_B = Fa/(a+b)
```

## 2.7 温度应力与装配应力

### 温度应力

杆件受约束时，温度变化会产生内力：

```
  自由膨胀量：δ_T = α · ΔT · l

  α：线膨胀系数（1/°C）
  ΔT：温度变化量（°C）
  l：杆件原长
  
  钢的 α ≈ 12×10⁻⁶ /°C
```

### 装配应力

构件尺寸有微小偏差时，强制装配产生的应力。

## 本章公式总结

| 公式 | 用途 |
|------|------|
| σ = F_N / A | 横截面正应力 |
| Δl = F_N·l / (EA) | 轴向变形 |
| σ_α = σ·cos²α | 斜截面正应力 |
| τ_α = (σ/2)·sin2α | 斜截面剪应力 |
| σ ≤ [σ] | 强度条件 |
| δ_T = α·ΔT·l | 自由热膨胀量 |

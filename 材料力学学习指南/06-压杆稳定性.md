# 第六章 压杆稳定性

## 6.1 稳定性的概念

受压杆件不仅可能因强度不足而破坏，还可能因**失稳**（突然弯曲）而破坏。

```
    稳定与不稳定的直观理解：

    小球在凹面上（稳定）：     小球在凸面上（不稳定）：
    
           ●                        ╱  ╲
         ╱   ╲                    ╱  ●  ╲
       ╱   ↓   ╲                ╱   ↓    ╲
    ──╱─────────╲──          ──╱──────────╲──
    
    受扰动后能恢复             受扰动后偏离越来越大
```

### 压杆失稳现象

```
    逐渐增大压力 F：

    F < F_cr：           F = F_cr：           F > F_cr：
    
    ↓F                   ↓F                   ↓F
    ║                    ║╲                   ║  ╲
    ║                    ║  ╲                 ║    ╲
    ║ 保持直线           ║    ╲ 刚好弯曲      ║      ╲ 严重弯曲
    ║                    ║   ╱                ║     ╱   → 破坏
    ║                    ║ ╱                  ║   ╱
    ▽                    ▽                    ▽
    
    F_cr：临界力（使压杆刚好失稳的最小力）
```

## 6.2 欧拉公式（细长杆临界力）

### 两端铰支的细长压杆（基本情况）

```
  ┌──────────────────────────────────┐
  │          π² · E · I_min          │
  │  F_cr = ─────────────────        │
  │              l²                  │
  │                                  │
  │  F_cr ：临界力（N）              │
  │  E   ：弹性模量（MPa）           │
  │  I_min：最小惯性矩（mm⁴）       │
  │  l   ：杆长（mm）               │
  └──────────────────────────────────┘
```

### 不同端部约束条件

通过引入**长度系数 μ**，将各种约束统一为：

```
  ┌──────────────────────────────────┐
  │          π² · E · I_min          │
  │  F_cr = ─────────────────        │
  │            (μl)²                 │
  │                                  │
  │  μl = 等效长度（相当长度）        │
  └──────────────────────────────────┘
```

### 四种典型约束的长度系数

```
  ① 两端铰支          ② 一端固定一端自由    ③ 一端固定一端铰支    ④ 两端固定
  
     ↓F                  ↓F                    ↓F                   ↓F
     ○                   │                     ○                    ▌
     ║                   ║                     ║                    ║
     ║                   ║                     ║                    ║
     ║                   ║                     ║                    ║
     ║                   ║                     ║                    ║
     △                   ▌                     ▌                    ▌
     
     μ = 1               μ = 2                 μ = 0.7              μ = 0.5
     
  约束越强 → μ越小 → 临界力越大 → 越稳定
```

### 临界力对比

| 约束条件 | μ | F_cr |
|----------|---|------|
| 两端铰支 | 1.0 | π²EI/l² |
| 一固一自由 | 2.0 | π²EI/(4l²) ← 最小 |
| 一固一铰 | 0.7 | 2π²EI/l² |
| 两端固定 | 0.5 | 4π²EI/l² ← 最大 |

## 6.3 临界应力与柔度

### 临界应力

```
         F_cr     π²E
  σ_cr = ──── = ────────
          A      λ²

  λ：柔度（长细比）
```

### 柔度（长细比）

```
  ┌──────────────────────┐
  │       μl             │
  │  λ = ────            │
  │       i              │
  │                      │
  │  i = √(I_min/A)     │
  │  i：最小回转半径      │
  │  λ越大 → 杆越细长    │
  │       → 越容易失稳   │
  └──────────────────────┘
```

### 临界应力总图（三种情况）

```
  σ_cr
  ↑
  │  σ_s ┌────────────╮
  │      │             ╲
  │      │  ② 中柔度杆  ╲  ① 大柔度杆（细长杆）
  │      │  （经验公式）   ╲  σ_cr = π²E/λ²（欧拉公式）
  │      │     直线公式     ╲
  │  σ_p │                   ╲
  │      │                    ╲
  │      │                     ╲────────
  │      │                              
  └──────┴──────────┴──────────┴────→ λ
  ③短粗杆   λ_p        λ_s
  强度问题
  σ_cr=σ_s

  ① λ > λ_s ：大柔度杆，用欧拉公式
  ② λ_p < λ < λ_s ：中柔度杆，用经验公式（直线公式或抛物线公式）
  ③ λ < λ_p ：短粗杆，不是稳定性问题，按强度计算
```

## 6.4 压杆稳定性校核

### 安全系数法

```
  ┌──────────────────────────────────┐
  │                                  │
  │        F_cr                      │
  │  n = ────── ≥ n_st               │
  │         F                        │
  │                                  │
  │  n   ：稳定安全系数              │
  │  n_st：许用稳定安全系数          │
  │       （一般 n_st = 1.5 ~ 3.0） │
  └──────────────────────────────────┘
```

### 折减系数法

```
  ┌──────────────────────────────────┐
  │                                  │
  │       F                          │
  │  σ = ─── ≤ φ · [σ]              │
  │       A                          │
  │                                  │
  │  φ：稳定系数（折减系数）         │
  │    由柔度 λ 查表或计算得到       │
  │    0 < φ ≤ 1                     │
  │    λ越大 → φ越小                 │
  └──────────────────────────────────┘
```

## 6.5 提高压杆稳定性的措施

```
  ┌─────────────────────────────────────────────┐
  │                                             │
  │  F_cr = π²EI_min / (μl)²                    │
  │                                             │
  │  要增大 F_cr，可以：                         │
  │                                             │
  │  ① 减小等效长度 μl                           │
  │     → 增加中间支撑（减小 l）                 │
  │     → 改善端部约束（减小 μ）                 │
  │                                             │
  │  ② 增大 I_min                               │
  │     → 选择合理截面形状                       │
  │     → 使 I_min 尽量大（如圆管、工字钢）      │
  │     → 避免 I 在某个方向特别小                │
  │                                             │
  │  ③ 选用 E 较大的材料（效果有限）             │
  │                                             │
  └─────────────────────────────────────────────┘
```

### 截面选择原则

```
    不好的截面         好的截面
    (I_min 很小)       (I_min 较大, 各方向接近)
    
    ┌──────┐           ╱────╲
    │      │          │      │      ┌──┐
    │      │          │      │      │  ├──┐
    │      │           ╲────╱       │  │  │
    └──────┘           圆管截面     ├──┘  │
    扁矩形截面                      └──┬──┘
    I_min ≈ bh³/12                  工字钢截面
    (h方向的I很小)
```

## 6.6 例题

```
    已知：两端铰支钢柱，长 l = 3 m，截面为直径 d = 60 mm 的实心圆
          E = 200 GPa，σ_s = 235 MPa
    
    求：临界力 F_cr
    
    解：
    ① 截面参数：
       A = πd²/4 = π×60²/4 = 2827 mm²
       I = πd⁴/64 = π×60⁴/64 = 636,173 mm⁴
       i = √(I/A) = √(636173/2827) = 15 mm
    
    ② 柔度：
       λ = μl/i = 1×3000/15 = 200
    
    ③ 判断类型：λ = 200 很大 → 属于大柔度杆
       用欧拉公式
    
    ④ 临界力：
       F_cr = π²EI/(μl)²
            = π²×200×10³×636173 / (1×3000)²
            = 139,490 N ≈ 139.5 kN
    
    ⑤ 验证：σ_cr = F_cr/A = 139490/2827 = 49.3 MPa < σ_p
       确认在弹性范围内，欧拉公式适用 ✓
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| F_cr = π²EI_min/(μl)² | 欧拉临界力 |
| σ_cr = π²E/λ² | 临界应力 |
| λ = μl/i | 柔度（长细比） |
| i = √(I_min/A) | 回转半径 |
| σ = F/A ≤ φ[σ] | 折减系数法校核 |

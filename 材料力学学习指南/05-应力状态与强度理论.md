# 第五章 应力状态与强度理论

## 5.1 应力状态的概念

前面讨论的拉伸、扭转、弯曲都是在**特定截面**上求应力。但实际上，材料内部一个点在**不同方向的截面**上有不同的应力，这就是**应力状态**。

### 为什么要研究应力状态？

```
  单向拉伸的钢杆：        铸铁受扭：
  
  ──══════──              ════════
    →F    F←              ⟳T   T⟲
  
  断裂面与轴线成45°       断裂面与轴线成45°
  （沿最大剪应力面）       （沿最大拉应力面）
  
  说明：破坏不一定发生在最大正应力截面上！
  必须分析各个方向上的应力。
```

---

## 5.2 应力状态的分类

### 单元体

取材料中一个**无限小**的正六面体来研究各面上的应力：

```
    三维应力状态（一般应力状态）：
    
              σ_z
              ↑ τ_zy
              │╱
         τ_xz │    τ_zx
    ┌─────────┼─────────→ σ_x
    │ σ_y←    │     ╱ τ_xy
    │   τ_yx  │   ╱
    │         │ ╱ τ_yz
    └─────────↓
```

### 三种应力状态

```
  ① 单向应力状态：只有一个方向的主应力不为零
  
     → σ₁ ─┌──────┐── σ₁ →
            │      │
            └──────┘
  
  ② 平面应力状态：有两个方向的主应力不为零
  
     → σ₁ ─┌──────┐── σ₁ →
        σ₂↑│      │↓σ₂
            └──────┘
  
  ③ 三向应力状态：三个方向的主应力都不为零
```

---

## 5.3 平面应力状态分析

### 斜截面上的应力

已知单元体上 σ_x, σ_y, τ_xy，求任意斜截面（法线与 x 轴成 α 角）上的应力：

```
    ┌──────────────────────────────────────────────────┐
    │                                                  │
    │        σ_x + σ_y     σ_x - σ_y                  │
    │ σ_α = ─────────── + ─────────── cos2α + τ_xy sin2α │
    │            2              2                      │
    │                                                  │
    │        σ_x - σ_y                                 │
    │ τ_α = -─────────── sin2α + τ_xy cos2α           │
    │             2                                    │
    │                                                  │
    └──────────────────────────────────────────────────┘
```

### 主应力

**主应力**：剪应力为零的截面上的正应力（极值正应力）。

```
  ┌─────────────────────────────────────────────────────┐
  │                                                     │
  │          σ_x + σ_y       ┌──────────────────────    │
  │ σ₁,₃ = ─────────── ±   √│(σ_x - σ_y)² / 4 + τ_xy²│
  │              2           └──────────────────────    │
  │                                                     │
  │ σ₁ ≥ σ₂ ≥ σ₃（按大小排列）                         │
  │ 平面问题中 σ₂ = 0                                   │
  │                                                     │
  └─────────────────────────────────────────────────────┘
```

主方向角：

```
                 2τ_xy
  tan 2α₀ = ───────────
              σ_x - σ_y
```

### 最大剪应力

```
         σ₁ - σ₃
  τ_max = ─────────
              2

  最大剪应力面与主应力面成 45°
```

## 5.4 莫尔圆（应力圆）

莫尔圆是分析应力状态的**图解法**，非常直观。

### 绘制步骤

```
  ① 建立 σ-τ 坐标系（σ 为横轴，τ 为纵轴）
  ② 标出两个点：
     A(σ_x, τ_xy)  — x 面上的应力
     B(σ_y, -τ_xy) — y 面上的应力
  ③ 连接 AB，交 σ 轴于 C 点，C 为圆心
  ④ 以 CA 为半径画圆
```

### 莫尔圆图示

```
    τ
    ↑
    │        A(σ_x, τ_xy)
    │       ╱●
    │      ╱   ╲
    │     ╱     ╲
    │    ╱       ╲
    ├───●─────────●──────●───→ σ
    │  σ₃╲   C   ╱     σ₁
    │     ╲     ╱
    │      ╲   ╱
    │       ╲ ╱
    │        ●B(σ_y, -τ_xy)
    │
    
    圆心 C 坐标：((σ_x + σ_y)/2, 0)
    
    半径 R = √[(σ_x - σ_y)²/4 + τ_xy²]
    
    σ₁ = C + R（圆与 σ 轴右交点）
    σ₃ = C - R（圆与 σ 轴左交点）
    τ_max = R  （圆的最高点）
```

### 莫尔圆的应用

```
  从莫尔圆上可以直接读出：
  
  ✓ 主应力 σ₁, σ₃
  ✓ 最大剪应力 τ_max
  ✓ 主方向角 α₀（圆上角度 = 实际角度的 2 倍）
  ✓ 任意斜截面的 σ_α 和 τ_α
```

> **与仿真的联系**：在 ANSYS/Abaqus 后处理中，查看 "Principal Stresses" 就是主应力，"Von Mises Stress" 则是基于主应力的等效应力（见下节强度理论）。

## 5.5 广义胡克定律

三维应力状态下的应力-应变关系：

```
  ┌──────────────────────────────────────────────┐
  │                                              │
  │  ε_x = [σ_x - μ(σ_y + σ_z)] / E            │
  │                                              │
  │  ε_y = [σ_y - μ(σ_x + σ_z)] / E            │
  │                                              │
  │  ε_z = [σ_z - μ(σ_x + σ_y)] / E            │
  │                                              │
  │  γ_xy = τ_xy / G                            │
  │  γ_yz = τ_yz / G                            │
  │  γ_xz = τ_xz / G                            │
  │                                              │
  └──────────────────────────────────────────────┘
```

> 注意：每个方向的应变不仅取决于该方向的应力，还受另外两个方向应力的影响（通过泊松比 μ）。

## 5.6 四大强度理论

材料在复杂应力状态下的破坏判据：

### 第一强度理论（最大拉应力理论）

```
  σ₁ ≤ [σ]

  适用：脆性材料，拉伸破坏
  认为：最大拉应力达到极限值时材料断裂
```

### 第二强度理论（最大伸长线应变理论）

```
  σ₁ - μ(σ₂ + σ₃) ≤ [σ]

  适用较少，了解即可
```

### 第三强度理论（最大剪应力理论）— Tresca 准则

```
  σ₁ - σ₃ ≤ [σ]

  适用：塑性材料
  认为：最大剪应力达到极限值时材料屈服
  
  等效应力：σ_r3 = σ₁ - σ₃
```

### 第四强度理论（形状改变比能理论）— von Mises 准则

```
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │         1                                               │
  │  σ_r4 = ─── √[(σ₁-σ₂)² + (σ₂-σ₃)² + (σ₃-σ₁)²] ≤ [σ] │
  │         √2                                              │
  │                                                         │
  └─────────────────────────────────────────────────────────┘

  适用：塑性材料（比第三理论更精确）
  认为：形状改变比能达到极限值时材料屈服
```

### 强度理论对比表

| 理论 | 准则 | 适用材料 | 仿真中的名称 |
|------|------|----------|-------------|
| 第一 | σ₁ ≤ [σ] | 脆性 | Max Principal Stress |
| 第三 | σ₁ - σ₃ ≤ [σ] | 塑性 | Tresca Stress |
| 第四 | von Mises 公式 | 塑性（最常用） | **Von Mises Stress** |

> **仿真提示**：在 ANSYS/Abaqus 中最常用的是 **Von Mises 等效应力**。后处理时选择 "Equivalent (von-Mises) Stress"，将其与材料的屈服强度 σ_s 对比，即可判断结构是否安全。

## 5.7 组合变形的强度计算

实际构件往往同时受到多种载荷，需要用强度理论来校核。

### 弯扭组合（最常见）

传动轴常同时受弯矩 M 和扭矩 T：

```
    危险点的应力状态：
    
    ┌──────┐
    │  ↑τ  │  σ = M/W_z（弯曲正应力）
    │      │  τ = T/W_t（扭转剪应力）
    │σ→  ←σ│
    │      │
    │  ↓τ  │
    └──────┘
    
    按第三强度理论：
    σ_r3 = √(σ² + 4τ²) ≤ [σ]
    
    按第四强度理论：
    σ_r4 = √(σ² + 3τ²) ≤ [σ]
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| σ₁,₃ = (σ_x+σ_y)/2 ± √[((σ_x-σ_y)/2)² + τ_xy²] | 主应力 |
| τ_max = (σ₁ - σ₃) / 2 | 最大剪应力 |
| tan2α₀ = 2τ_xy / (σ_x - σ_y) | 主方向角 |
| σ_r3 = σ₁ - σ₃ | 第三强度理论等效应力 |
| σ_r4 = √[(σ₁-σ₂)²+(σ₂-σ₃)²+(σ₃-σ₁)²] / √2 | 第四强度理论 (von Mises) |
| σ_r = √(σ²+4τ²) | 弯扭组合（第三理论） |

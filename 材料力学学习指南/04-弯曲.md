# 第四章 弯曲

弯曲是材料力学中**最重要、最常考**的内容，也是有限元分析中最常见的变形类型。

## 4.1 弯曲的基本概念

### 梁的分类

```
    ① 简支梁：
    △                    ○
    ═══════════════════════
    A                     B
    （一端铰支座，一端滚动支座）

    ② 悬臂梁：
    ▌═══════════════════════
    A（固定端）              B（自由端）

    ③ 外伸梁：
              △                    ○
    ══════════╪════════════════════╪══════
              A                    B
    （支座外有伸出部分）
```

### 载荷类型

```
    集中力 F：             集中力偶 M：          分布力 q：
    
         F↓                    ⟳M                ↓↓↓↓↓↓↓↓ q
    ═════╪══════          ═════╪══════          ═══════════════
```

## 4.2 剪力与弯矩

### 用截面法求内力

在截面处将梁切开，对左段（或右段）取平衡：

```
    简支梁受集中力：
    
         F↓
    △════╪════════○
    A    C         B
    ↑R_A    l      ↑R_B
    ├─a─┤├──b──┤

    求支反力：
    ΣM_A = 0:  R_B·l - F·a = 0  →  R_B = Fa/l
    ΣM_B = 0:  R_A·l - F·b = 0  →  R_A = Fb/l
    
    截面 C 的左侧：
    ΣFy = 0:   R_A - F_Q = 0    →  F_Q = Fb/l
    ΣM_C = 0:  M - R_A·a = 0    →  M = Fab/l
```

### 剪力与弯矩的符号规定

```
    正剪力：                    负剪力：
    
    ══╪══                      ══╪══
      ↓F_Q（左段向下）             ↑F_Q（左段向上）
      ↑F_Q（右段向上）             ↓F_Q（右段向下）
      
    "左下右上为正"

    正弯矩：                    负弯矩：
    
       ╱  ╲                     ╲  ╱
    ══╱────╲══                ══╲────╱══
      （下凸为正）                （上凸为负）
      
    "使梁下凸（受拉）为正"
```

## 4.3 剪力图与弯矩图

### 画图步骤

```
  ① 求支反力
  ② 分段（每个集中力/集中力偶处为分界点）
  ③ 对每段列 F_Q(x) 和 M(x) 表达式
  ④ 画图
```

### 微分关系（非常重要！）

```
  ┌───────────────────────────────────────┐
  │                                       │
  │  dF_Q / dx = -q(x)    载荷 → 剪力    │
  │                                       │
  │  dM / dx = F_Q(x)     剪力 → 弯矩    │
  │                                       │
  │  d²M / dx² = -q(x)   载荷 → 弯矩    │
  │                                       │
  └───────────────────────────────────────┘
  
  物理含义：
  • 无载荷段：剪力图为水平线，弯矩图为斜线
  • 均布载荷段：剪力图为斜线，弯矩图为抛物线
  • 集中力处：剪力图突变，弯矩图转折
  • 集中力偶处：弯矩图突变
  • 剪力为零处：弯矩取极值
```

### 典型梁的内力图

**例1：简支梁受跨中集中力**

```
    载荷图：
              F↓
    △═════════╪═════════○
    A        l/2         B
    ↑F/2                 ↑F/2

    剪力图 F_Q：
    F/2 ┌─────────┐
        │         │
    ────┘         └──── 0
                  │
       -F/2      └─────

    弯矩图 M：
                ╱╲ Fl/4（最大弯矩）
              ╱    ╲
            ╱        ╲
    ──────╱────────────╲───── 0
    A                    B
```

**例2：悬臂梁受端部集中力**

```
    载荷图：
                       F↓
    ▌══════════════════╪
    A                   B
    ├──── l ────────────┤

    剪力图 F_Q：
           ┌──────────── F
    ───────┘                    
    A                   B

    弯矩图 M：
    ───────────────────── 0
    A ╲                  B
        ╲
          ╲
            ╲
       -Fl   ╲─────────
    
    最大弯矩在固定端：M_max = -Fl
```

**例3：简支梁受均布载荷**

```
    载荷图：
    ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓ q
    △═══════════════════○
    A         l          B
    ↑ql/2               ↑ql/2

    剪力图 F_Q（斜线，中点过零）：
    ql/2 ╲
          ╲
           ╲
    ────────╲──────── 0
              ╲
               ╲
                ╲ -ql/2

    弯矩图 M（抛物线，中点最大）：
              ╱╲  ql²/8
            ╱    ╲
          ╱        ╲
    ────╱────────────╲──── 0
    A                  B
    
    最大弯矩在跨中：M_max = ql²/8
```

## 4.4 弯曲正应力

### 中性层与中性轴

```
    梁弯曲时的截面变形：
    
    ─────────── → 受压（缩短）σ < 0
    ─────────── 
    ─ ─ ─ ─ ─ ─ 中性层（不伸不缩）σ = 0
    ─────────── 
    ─────────── → 受拉（伸长）σ > 0
    
    中性轴 = 中性层与横截面的交线
    中性轴通过截面形心
```

### 弯曲正应力公式

```
  ┌──────────────────────────────┐
  │        M · y                 │
  │  σ = ────────   （任意点）   │
  │        I_z                   │
  │                              │
  │        M                     │
  │  σ_max = ────  （最外边缘）  │
  │        W_z                   │
  │                              │
  │  y  ：该点到中性轴的距离      │
  │  I_z：截面对中性轴的惯性矩   │
  │  W_z：抗弯截面系数 = I_z/y_max│
  └──────────────────────────────┘
```

### 应力分布图

```
    矩形截面弯曲应力分布：
    
    σ_max(压) ←──── ┌──────┐
                  ╱ │      │
                ╱   │      │
              ╱     │      │  h
    中性轴 ──·──────│──────│──
              ╲     │      │
                ╲   │      │
                  ╲ │      │
    σ_max(拉) ────→ └──────┘
                       b
    
    线性分布：中性轴处为零，上下边缘最大
```

### 常用截面的惯性矩与抗弯截面系数

| 截面形状 | 惯性矩 I_z | 抗弯截面系数 W_z |
|----------|-----------|----------------|
| 矩形 (b×h) | bh³/12 | bh²/6 |
| 圆形 (直径 d) | πd⁴/64 | πd³/32 |
| 空心圆 (D, d) | π(D⁴-d⁴)/64 | π(D⁴-d⁴)/(32D) |
| 工字钢 | 查手册 | 查手册 |

> **为什么工字钢效率高？** 弯曲正应力最大值在最外边缘，工字钢将材料集中在离中性轴最远处（翼缘），减少中间部分材料（腹板变薄），同样材料获得更大的 W_z。

## 4.5 弯曲剪应力

### 矩形截面的弯曲剪应力

```
  ┌──────────────────────────────────┐
  │       F_Q · S_z*                 │
  │  τ = ──────────                  │
  │       I_z · b                    │
  │                                  │
  │  S_z*：截面上距中性轴 y 处以外   │
  │        部分对中性轴的静矩        │
  └──────────────────────────────────┘
```

矩形截面上剪应力呈**抛物线分布**：

```
    剪应力分布（矩形截面）：
    
    ┌──────┐  τ = 0（上边缘）
    │  ╱   │
    │ ╱    │
    │╱     │  τ_max = 3F_Q/(2A)（中性轴处）
    │╲     │
    │ ╲    │
    │  ╲   │
    └──────┘  τ = 0（下边缘）
```

## 4.7 梁的挠度与转角（变形）

### 基本概念

```
    变形后的梁：
    
    ───────────────────── 原位置
            ╲
              ╲  θ（转角）
                ╲
    ──────────────╲──── 挠曲线
                   │
                   │ w（挠度）
                   ↓
```

- **挠度** w：截面形心沿垂直方向的位移
- **转角** θ：截面绕中性轴的转动角度

### 挠曲线近似微分方程

```
  ┌───────────────────────────────┐
  │                               │
  │  EI · w'' = M(x)              │
  │                               │
  │  EI：抗弯刚度                  │
  │  w''：挠度的二阶导数           │
  │  M(x)：弯矩方程               │
  └───────────────────────────────┘
  
  积分一次得转角：EI·w' = EI·θ = ∫M(x)dx + C₁
  积分两次得挠度：EI·w = ∫∫M(x)dxdx + C₁x + C₂
  
  由边界条件确定积分常数 C₁, C₂
```

### 常用边界条件

| 支撑类型 | 条件 |
|----------|------|
| 铰支座处 | w = 0 |
| 固定端 | w = 0 且 θ = 0 |
| 自由端 | 无约束 |
| 对称中心 | θ = 0 |

### 典型梁的挠度与转角（背诵！）

| 梁型 | 最大挠度 w_max | 最大转角 θ_max |
|------|--------------|---------------|
| 简支梁跨中集中力 F | Fl³/(48EI) (跨中) | Fl²/(16EI) (支座处) |
| 简支梁均布载荷 q | 5ql⁴/(384EI) (跨中) | ql³/(24EI) (支座处) |
| 悬臂梁端部集中力 F | Fl³/(3EI) (自由端) | Fl²/(2EI) (自由端) |
| 悬臂梁均布载荷 q | ql⁴/(8EI) (自由端) | ql³/(6EI) (自由端) |

### 叠加法

复杂载荷 = 简单载荷之和，变形也可以叠加：

```
    ↓F    ↓↓↓↓↓↓↓q        ↓F              ↓↓↓↓↓↓↓q
    △═══════════○    =    △═══════════○  + △═══════════○
    
    w_总 = w_F + w_q      θ_总 = θ_F + θ_q
```

### 刚度条件

```
  w_max ≤ [w]     （许用挠度）
  θ_max ≤ [θ]     （许用转角）
  
  常见许用挠度：一般梁 [w] = l/250 ~ l/500
```

## 4.8 提高弯曲强度和刚度的措施

```
  1. 合理安排载荷和支座
     → 减小 M_max

  2. 选择合理的截面形状
     → 增大 W_z（如工字钢、T型、箱型截面）

  3. 使用高强度材料
     → 提高 [σ]

  4. 增大截面惯性矩
     → 增大 EI（提高刚度）
```

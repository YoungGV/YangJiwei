## 学习建议

1. **按顺序学习**：每章内容是递进关系，前面的概念是后面的基础
2. **重视画图**：材料力学离不开内力图、应力图，一定要动手画
3. **多做例题**：每个公式都要通过实际计算来掌握
4. **联系仿真**：学完每章后，尝试在 ANSYS 中建模验证

## 推荐配套教材

- 刘鸿文《材料力学》（第6版）— 国内经典教材
- 哈工大《材料力学》— 体系清晰，适合自学
- Gere & Goodno《Mechanics of Materials》— 国际经典，图示丰富

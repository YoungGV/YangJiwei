# 材料力学公式速查表

## 一、基本物理量

| 物理量 | 符号 | 公式 | 单位 |
|--------|------|------|------|
| 正应力 | σ | 内力 / 面积 | MPa (N/mm²) |
| 剪应力 | τ | 剪力 / 面积 | MPa |
| 线应变 | ε | Δl / l₀ | 无量纲 |
| 角应变 | γ | 直角改变量 | rad |

## 三、轴向拉伸与压缩

| 公式 | 说明 |
|------|------|
| σ = F_N / A | 横截面正应力 |
| Δl = F_N·l / (EA) | 轴向变形 |
| σ_α = σ·cos²α | 斜截面正应力 |
| τ_α = (σ/2)·sin2α | 斜截面剪应力 |
| δ_T = α·ΔT·l | 热膨胀量 |

**强度条件**：σ = F_N / A ≤ [σ]

## 四、剪切与挤压

**强度条件**：τ ≤ [τ]，σ_bs ≤ [σ_bs]

## 五、扭转

| 公式 | 说明 |
|------|------|
| T = 9549·P/n | 传动轴扭矩 (N·m)，P(kW)，n(r/min) |
| τ = T·ρ / I_p | 任意点剪应力 |
| τ_max = T / W_t | 最大剪应力（边缘处） |
| φ = Tl / (GI_p) | 扭转角 |
| φ' = T / (GI_p) | 单位长度扭转角 |

### 截面几何量

| 截面 | I_p | W_t |
|------|-----|-----|
| 实心圆 d | πd⁴/32 | πd³/16 |
| 空心圆 D,d (α=d/D) | πD⁴(1-α⁴)/32 | πD³(1-α⁴)/16 |

**强度条件**：τ_max = T / W_t ≤ [τ]

**刚度条件**：φ' = T / (GI_p) ≤ [φ']

## 九、应力状态

| 公式 | 说明 |
|------|------|
| σ₁,₃ = (σ_x+σ_y)/2 ± √[((σ_x-σ_y)/2)² + τ_xy²] | 主应力 |
| τ_max = (σ₁ - σ₃) / 2 | 最大剪应力 |
| tan2α₀ = 2τ_xy / (σ_x - σ_y) | 主方向角 |

### 广义胡克定律

```
ε_x = [σ_x - μ(σ_y + σ_z)] / E
ε_y = [σ_y - μ(σ_x + σ_z)] / E
ε_z = [σ_z - μ(σ_x + σ_y)] / E
```

## 十、强度理论

| 理论 | 等效应力 σ_r | 适用 |
|------|-------------|------|
| 第一（最大拉应力） | σ₁ | 脆性材料 |
| 第三（最大剪应力 / Tresca） | σ₁ - σ₃ | 塑性材料 |
| 第四（von Mises） | √[(σ₁-σ₂)²+(σ₂-σ₃)²+(σ₃-σ₁)²] / √2 | 塑性材料（最常用） |

### 弯扭组合

| 理论 | 公式 |
|------|------|
| 第三 | σ_r3 = √(σ² + 4τ²) |
| 第四 | σ_r4 = √(σ² + 3τ²) |

## 十一、压杆稳定

| 公式 | 说明 |
|------|------|
| F_cr = π²EI_min / (μl)² | 欧拉临界力 |
| σ_cr = π²E / λ² | 临界应力 |
| λ = μl / i | 柔度（长细比） |
| i = √(I_min / A) | 回转半径 |

### 长度系数 μ

| 约束 | 两端铰支 | 一固一自由 | 一固一铰 | 两端固定 |
|------|---------|-----------|---------|---------|
| μ | 1.0 | 2.0 | 0.7 | 0.5 |

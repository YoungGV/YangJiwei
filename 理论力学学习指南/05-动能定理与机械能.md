# 第五章 动能定理与机械能

动量定理解决力和时间的关系，动能定理解决力和位移的关系。

## 5.1 功（Work）

### 常力的功

```
  ┌───────────────────────────────┐
  │                               │
  │  W = F · s · cosα             │
  │                               │
  │  F：力的大小                  │
  │  s：位移大小                  │
  │  α：力与位移方向的夹角        │
  │  单位：J（焦耳）= N·m        │
  └───────────────────────────────┘
```

```
    功的正负：
    
    α < 90°：W > 0（正功，力与运动同向）
    
       F⃗↗
      ╱ α
    ●──────→ s⃗
    
    α = 90°：W = 0（力与运动垂直，如法向力）
    
    α > 90°：W < 0（负功，如摩擦力做负功）
```

### 变力的功

```
  W = ∫ F⃗ · dr⃗ = ∫(F_x dx + F_y dy + F_z dz)
```

### 各种力做功的公式

| 力 | 功的公式 | 说明 |
|----|----------|------|
| 重力 | W_G = mgh | h 为质心下降的高度 |
| 弹簧弹力 | W = ½k(x₁² - x₂²) | k 为弹簧刚度 |
| 摩擦力 | W_f = -μmgs | 始终做负功 |
| 力偶 | W_M = M·φ | φ 为转过的角度 |

```
    重力做功：
    
    ●  h₁（高位置）
    │
    │ ↓ mg
    │ h = h₁ - h₂（下降高度）
    │
    ● h₂（低位置）
    
    W_G = mg·h（下降为正功，上升为负功）
    与路径无关！→ 重力是保守力
```

```
    弹簧弹力做功：
    
    ──╫──●──────→ x
      0  x₁  →  x₂
    
    ├─ 自然长度 ─┤
    
    W = ½k·x₁² - ½k·x₂²
    
    从变形大的位置到变形小的位置：弹力做正功
```

### 功率

```
  ┌──────────────────────────┐
  │                          │
  │  P = dW/dt = F⃗ · v⃗     │
  │                          │
  │  P = F·v·cosα            │
  │                          │
  │  转动时：P = M·ω         │
  │                          │
  │  单位：W（瓦特）          │
  │  1 kW = 1000 W           │
  │  1 马力 ≈ 735.5 W        │
  └──────────────────────────┘
```

## 5.2 动能

### 质点与质点系的动能

```
  ┌──────────────────────────────────┐
  │  质点：T = ½mv²                  │
  │                                  │
  │  质点系：T = Σ ½m_i·v_i²         │
  │                                  │
  │  平动刚体：T = ½Mv_c²            │
  │                                  │
  │  定轴转动刚体：T = ½Jω²          │
  │                                  │
  │  平面运动刚体：T = ½Mv_c² + ½J_cω²│
  │              （平动 + 转动）      │
  └──────────────────────────────────┘
```

```
    刚体动能的三种情况：

    平动            定轴转动         平面运动
    
    ──→ v_c         ──╲              ──→ v_c
    ┌──┐             ╱│╲              ┌──┐╲
    │  │            │ ω │             │ω │  ╲
    └──┘             ╲│╱              └──┘    
                      
    T = ½Mv_c²     T = ½Jω²        T = ½Mv_c² + ½J_cω²
```

### 纯滚动的动能

```
    圆轮在地面上纯滚动（无滑动）：
    
           v_c →
          ╭───╮
         │  ω │    v_c = Rω（纯滚动条件）
          ╰───╯
    ──────●──────── 瞬心（接触点速度为零）
    
    T = ½Mv_c² + ½J_c·ω²
    
    均质圆盘 J_c = ½mR²：
    T = ½mR²ω² + ½·½mR²·ω² = ¾mR²ω² = ¾mv_c²
```

## 5.3 动能定理

### 质点的动能定理

```
  ┌──────────────────────────────────┐
  │                                  │
  │  T₂ - T₁ = ΣW_i                 │
  │                                  │
  │  末动能 - 初动能 = 所有力做功之和 │
  │                                  │
  └──────────────────────────────────┘
```

### 质点系的动能定理

```
  ┌──────────────────────────────────────┐
  │                                      │
  │  T₂ - T₁ = ΣW_i(外) + ΣW_i(内)     │
  │                                      │
  │  系统动能变化 = 所有力（外力+内力）   │
  │                做功之和              │
  │                                      │
  │  注意：内力的功不一定为零！           │
  │  （如弹簧、爆炸等）                  │
  └──────────────────────────────────────┘
```

### 例题：滑轮系统

```
    物体 A（质量 m₁）通过绳子经过滑轮
    连接物体 B（质量 m₂），m₁ > m₂
    滑轮质量 m₀，半径 R
    初速度为零，求 A 下降 h 后的速度
    
           ┌──○──┐（滑轮）
           │     │
    ┌──┐   │     │   ┌──┐
    │A │   │     │   │B │
    │m₁│   │     │   │m₂│
    └──┘   │     │   └──┘
           ↓           ↑
    
    用动能定理（一步到位！）：
    
    T₁ = 0（初始静止）
    
    T₂ = ½m₁v² + ½m₂v² + ½J₀ω²
       = ½m₁v² + ½m₂v² + ½·½m₀R²·(v/R)²
       = ½(m₁ + m₂ + m₀/2)v²
    
    做功 = m₁gh - m₂gh = (m₁-m₂)gh
    
    T₂ - T₁ = ΣW
    ½(m₁ + m₂ + m₀/2)v² = (m₁-m₂)gh
    
    v = √[2(m₁-m₂)gh / (m₁ + m₂ + m₀/2)]
```

## 5.4 势能与机械能守恒

### 势能（位能）

```
  重力势能：V_g = mgh    （h 为距参考面的高度）
  弹性势能：V_e = ½kx²   （x 为弹簧变形量）
  
  保守力做功 = 势能的减少
  W = V₁ - V₂ = -(V₂ - V₁)
```

### 机械能守恒定律

```
  ┌──────────────────────────────────────────┐
  │  当系统只有保守力（重力、弹力）做功时：    │
  │                                          │
  │  T₁ + V₁ = T₂ + V₂                      │
  │                                          │
  │  机械能 E = T + V = 常量                 │
  │                                          │
  │  即：动能 + 势能 = 恒定                   │
  └──────────────────────────────────────────┘
  
  有非保守力（如摩擦力）做功时，机械能不守恒：
  T₂ + V₂ - (T₁ + V₁) = W_非保守
```

### 例题：单摆

```
    单摆从水平位置自由释放：
    
    O───────── ● A（初始位置，水平）
    │        ╱ l
    │      ╱
    │    ╱
    │  ● B（最低点）
    
    取 B 为势能零点：
    V_A = mgl,  T_A = 0
    V_B = 0,    T_B = ½mv_B²
    
    机械能守恒：
    T_A + V_A = T_B + V_B
    0 + mgl = ½mv_B² + 0
    
    v_B = √(2gl)
```

## 5.5 动力学普遍定理的比较

```
  ┌───────────┬──────────────┬──────────────┬──────────────┐
  │  定理      │   关联物理量  │   关联量     │   适用条件    │
  ├───────────┼──────────────┼──────────────┼──────────────┤
  │  动量定理  │  p⃗ = mv⃗    │  力 × 时间   │  求速度、力  │
  │           │              │  （冲量）     │  碰撞问题    │
  ├───────────┼──────────────┼──────────────┼──────────────┤
  │  动量矩   │  L = Jω     │  力矩 × 时间  │  求角速度    │
  │  定理     │              │              │  转动问题    │
  ├───────────┼──────────────┼──────────────┼──────────────┤
  │  动能定理  │  T = ½mv²   │  力 × 位移   │  求速度大小  │
  │           │              │  （功）       │  最万能！    │
  └───────────┴──────────────┴──────────────┴──────────────┘
  
  选择定理的口诀：
  「求速度大小用动能，
    求时间变化用动量，
    求转动问题用动量矩。」
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| W = Fs·cosα | 常力的功 |
| P = Fv·cosα = Mω | 功率 |
| T = ½mv² | 质点动能 |
| T = ½Mv_c² + ½J_cω² | 平面运动刚体动能 |
| T₂ - T₁ = ΣW | 动能定理 |
| V_g = mgh, V_e = ½kx² | 势能 |
| T₁ + V₁ = T₂ + V₂ | 机械能守恒 |

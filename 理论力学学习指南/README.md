## 理论力学三大板块

```
  理论力学
  ├── 静力学 ── 研究力的平衡条件（第一、二章）
  │              → 为材料力学、结构力学打基础
  │
  ├── 运动学 ── 研究运动的几何描述（第三章）
  │              → 不涉及力，只描述怎么动
  │
  └── 动力学 ── 研究力与运动的关系（第四、五、六章）
                  → 牛顿定律 + 三大定理 + 分析力学
```

## 学习建议

1. **静力学是地基**：受力分析和平衡方程是一切后续课程的基础
2. **多画受力图**：理论力学 = 画图 + 列方程，一定要动手
3. **运动学重视方法**：掌握自然坐标法和基点法
4. **动力学抓住三大定理**：动量、动量矩、动能定理能解决绝大多数问题

## 推荐配套教材

- 哈工大《理论力学》（第 8 版）— 国内使用最广泛的教材
- 梅凤翔《分析力学》— 进阶读物
- Meriam & Kraige《Engineering Mechanics》— 国际经典，图示清晰

# 第三章 运动学

运动学只研究运动的**几何描述**（位置、速度、加速度），不涉及力。

## 3.1 点的运动学

### 三种描述方法

```
  ① 矢径法（矢量法）
  ② 直角坐标法
  ③ 自然坐标法（弧坐标法）
```

### ① 矢径法

```
    y
    ↑      ● P(t)
    │    ╱
    │  r⃗(t)
    │╱
    └──────────→ x
    O
    
    位置：r⃗ = r⃗(t)
    速度：v⃗ = dr⃗/dt = ṙ⃗
    加速度：a⃗ = dv⃗/dt = r̈⃗
```

### ② 直角坐标法

```
  ┌─────────────────────────────────┐
  │  位置：x = x(t),  y = y(t)     │
  │                                 │
  │  速度：v_x = ẋ = dx/dt         │
  │        v_y = ẏ = dy/dt         │
  │        v = √(v_x² + v_y²)      │
  │                                 │
  │  加速度：a_x = ẍ = d²x/dt²     │
  │          a_y = ÿ = d²y/dt²     │
  │          a = √(a_x² + a_y²)    │
  └─────────────────────────────────┘
```

### ③ 自然坐标法（重要！）

沿轨迹建立坐标：**切线方向 τ** 和 **法线方向 n**

```
    轨迹曲线：
    
                    n（法向，指向曲率中心）
                    ↑
                    │
    ────────────────●──→ τ（切向，沿运动方向）
                  P │
                    │
                    ○ 曲率中心
                    ρ（曲率半径）
```

```
  ┌───────────────────────────────────────┐
  │  速度：v = ds/dt = ṡ  （沿切向）      │
  │                                       │
  │  加速度分解为两个分量：                 │
  │                                       │
  │  切向加速度：a_τ = dv/dt = s̈          │
  │    → 改变速度大小                      │
  │                                       │
  │  法向加速度：a_n = v²/ρ               │
  │    → 改变速度方向                      │
  │                                       │
  │  总加速度：a = √(a_τ² + a_n²)         │
  └───────────────────────────────────────┘
```

### 各种运动的加速度特征

```
  匀速直线运动：  a_τ = 0,  a_n = 0  → a = 0
  匀加速直线运动：a_τ = 常数, a_n = 0
  匀速圆周运动：  a_τ = 0,  a_n = v²/R（向心加速度）
  一般曲线运动：  a_τ ≠ 0,  a_n ≠ 0
  
  总加速度方向：
  
            a⃗
          ╱ │
        ╱   │ a_n
      ╱ θ   │
    ●────────┘
      a_τ
    
    tanθ = a_n / a_τ
```

## 3.2 刚体的基本运动

### 平动（Translation）

```
    刚体内各点的轨迹形状相同，
    任一时刻各点的速度和加速度都相等。
    
    平动前：          平动后：
    ┌──────┐         ┌──────┐
    │ A  B │   →     │ A' B'│
    │      │         │      │
    │ C  D │         │ C' D'│
    └──────┘         └──────┘
    
    AA' = BB' = CC' = DD'（所有点位移相同）
    
    → 只需研究一个点的运动即可！
```

### 定轴转动（Rotation about Fixed Axis）

```
    绕固定轴 z 转动：
    
    z 轴
    │
    │  ╱────────╲
    │╱     ●P     ╲
    ●───── R ──────│
    │╲            ╱    角位移 φ = φ(t)
    │  ╲────────╱      角速度 ω = dφ/dt = φ̇
    │                  角加速度 α = dω/dt = φ̈
    
    P 点的速度和加速度：
    v = Rω                  （R = 点到轴的距离）
    a_τ = Rα               （切向加速度）
    a_n = Rω² = v²/R       （法向加速度）
```

```
  ┌──────────────────────────────────────┐
  │  定轴转动公式：                        │
  │                                      │
  │  角位移：φ = φ(t)         (rad)      │
  │  角速度：ω = dφ/dt        (rad/s)    │
  │  角加速度：α = dω/dt      (rad/s²)   │
  │                                      │
  │  匀速转动：φ = ω₀t                   │
  │  匀变速转动：φ = ω₀t + ½αt²          │
  │              ω = ω₀ + αt             │
  │              ω² = ω₀² + 2αφ          │
  │                                      │
  │  （类比匀变速直线运动！）              │
  └──────────────────────────────────────┘
```

### 转速与角速度的关系

```
  ω = 2πn/60    （n 的单位：r/min）
  
  ω = 2πf      （f 的单位：Hz = 1/s）
```

## 3.3 点的合成运动

当参考系本身也在运动时，需要用合成运动分析。

### 三种运动

```
  ┌──────────────────────────────────────────┐
  │  绝对运动 ── 动点相对于定参考系的运动     │
  │  相对运动 ── 动点相对于动参考系的运动     │
  │  牵连运动 ── 动参考系相对于定参考系的运动 │
  │                                          │
  │  绝对 = 相对 + 牵连                       │
  └──────────────────────────────────────────┘
```

### 速度合成定理

```
  ┌─────────────────────────────┐
  │                             │
  │  v⃗_a = v⃗_r + v⃗_e          │
  │                             │
  │  v⃗_a：绝对速度             │
  │  v⃗_r：相对速度             │
  │  v⃗_e：牵连速度             │
  │                             │
  │  矢量相加（平行四边形法则） │
  └─────────────────────────────┘
```

```
    速度合成图示：
    
           v⃗_a
          ╱
        ╱
      ╱
    ●──────→ v⃗_e
    │╲
    │  ╲
    │    v⃗_r
    ↓
    
    v⃗_a = v⃗_r + v⃗_e（矢量三角形）
```

### 加速度合成定理

```
  牵连运动为平动时：
  a⃗_a = a⃗_r + a⃗_e
  
  牵连运动为转动时（需加科氏加速度）：
  
  ┌──────────────────────────────────┐
  │                                  │
  │  a⃗_a = a⃗_r + a⃗_e + a⃗_c        │
  │                                  │
  │  a⃗_c = 2ω⃗_e × v⃗_r             │
  │                                  │
  │  a_c：科氏加速度                 │
  │  ω_e：牵连角速度                 │
  │  v_r：相对速度                   │
  │  大小：a_c = 2ω_e · v_r · sinθ  │
  │  方向：将 v_r 绕 ω_e 转 90°     │
  └──────────────────────────────────┘
```

### 科氏加速度的方向判定

```
    ω_e（牵连转动角速度方向：逆时针）
    
    v_r →          a_c ↑
    
    将 v_r 沿 ω_e 方向转 90°：
    → 转 90°（逆时针）→ 得到 ↑
    
    所以 a_c 方向向上 ✓
```

## 3.4 刚体的平面运动

平面运动 = 平动 + 转动的叠加。

### 基点法

```
  ┌──────────────────────────────────────────┐
  │  取 A 为基点：                            │
  │                                          │
  │  v⃗_B = v⃗_A + v⃗_BA                      │
  │                                          │
  │  v⃗_BA = ω × r⃗_BA  （B 绕 A 转动的速度） │
  │  |v_BA| = ω · |AB|                      │
  │  方向：⊥AB，指向与 ω 一致的转向           │
  └──────────────────────────────────────────┘
```

```
    基点法图示：
    
    v_A →    A━━━━━━━━━━B
                         ╲
             v_BA ⊥ AB    ╲ v_B = v_A + v_BA
                           ↘
    
    v_B 由平行四边形法则确定
```

### 瞬时速度中心（速度瞬心）

平面运动刚体在每一瞬时都有一个速度为零的点，称为**瞬心**。

```
  ┌───────────────────────────────┐
  │  瞬心的求法：                  │
  │                               │
  │  ① 已知两点速度方向：          │
  │     过两点分别作速度的垂线，   │
  │     交点即为瞬心 P            │
  │                               │
  │  ② 纯滚动：                   │
  │     接触点即为瞬心             │
  └───────────────────────────────┘
```

```
    瞬心法求速度：
    
    v_A ↑         v_B →
    │  A━━━━━━━━━━B
    │╱              ╲
    P（瞬心）        ╲
                      ╲
    
    ω = v_A / PA = v_B / PB
    
    任意点 C 的速度：v_C = ω · PC，方向 ⊥ PC
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| v = ṡ, a_τ = s̈, a_n = v²/ρ | 自然坐标法 |
| v = Rω, a_τ = Rα, a_n = Rω² | 定轴转动上点的运动 |
| ω = dφ/dt, α = dω/dt | 角速度、角加速度 |
| v⃗_a = v⃗_r + v⃗_e | 速度合成定理 |
| a⃗_c = 2ω⃗_e × v⃗_r | 科氏加速度 |
| v⃗_B = v⃗_A + ω × r⃗_BA | 基点法（平面运动） |

# 第六章 达朗贝尔原理与虚位移原理

本章介绍两种非常强大的力学分析方法，前者将动力学问题转化为静力学问题，后者是分析力学的入门。

## 6.1 达朗贝尔原理（动静法）

### 核心思想

在加速运动的物体上引入一个假想的**惯性力**，使牛顿第二定律变成形式上的平衡方程。

```
  牛顿定律：  ΣF = ma
  
  移项：     ΣF + (-ma) = 0
                   ↑
                惯性力 F* = -ma
  
  ┌──────────────────────────────────┐
  │  ΣF + F* = 0    ← 形式上的平衡  │
  │                                  │
  │  F* = -m·a⃗    （惯性力）        │
  │  方向与加速度相反                 │
  │  大小等于 ma                     │
  └──────────────────────────────────┘
```

```
    例：加速上升的电梯中的物体
    
    实际分析（动力学）：    动静法分析（加惯性力）：
    
    ↑ N                    ↑ N
    │                      │
    ● m                    ● m         ΣF_y = 0
    │                      │           N - mg - ma = 0
    ↓ mg                   ↓ mg        N = m(g+a)
    加速度 a↑              ↓ F* = ma
    
    N - mg = ma            N - mg - ma = 0（平衡方程）
    N = m(g+a) ✓           N = m(g+a) ✓  同样的结果！
```

### 刚体转动的惯性力系简化

```
  定轴转动刚体的惯性力系可以简化为：
  
  ① 过质心的惯性力（平动惯性力）：
     F*_c = -m·a_c
  
  ② 对质心的惯性力偶矩：
     M*_c = -J_c·α
  
  ┌─────────────────────────────────┐
  │  惯性力系 = F*_c + M*_c         │
  │                                 │
  │  F*_c = m·a_c （方向与 a_c 反）│
  │  M*_c = J_c·α （方向与 α 反）  │
  └─────────────────────────────────┘
```

```
    定轴转动的惯性力系：
    
        ω, α ⟲
         │
    ─────●───── 转轴
         │╲
         │  ╲ a_c（质心加速度）
         ● C（质心）
         │
    
    惯性力：F*_c = m·a_c（方向与 a_c 反）
    惯性力偶：M*_c = J_c·α（方向与 α 反）
    
    然后当作静力学问题列平衡方程求解轴承反力等
```

### 例题：曲柄的轴承反力

```
    均质细杆 OA，质量 m，长 l，绕 O 点转动
    某瞬时 ω 和 α 已知，求 O 处轴承反力
    
         α ⟲, ω
    O────────●C────────A
    ↑        │（质心在中点）
    轴       ↓ mg
    
    加惯性力后（动静法）：
    
    → R_Ox      ← F*_n = m·(l/2)·ω²（法向惯性力）
    ↑ R_Oy                  
    O────────●C────────A
             │
             ↓ mg
             ↑ F*_τ = m·(l/2)·α（切向惯性力，与 α 反向）
             ⟲ M*_c = J_c·α = (ml²/12)·α
    
    列 3 个平衡方程求 R_Ox, R_Oy 和验证
```

## 6.2 虚位移原理

### 约束与自由度

```
  约束 ── 限制物体运动的条件
  自由度 ── 确定系统位置所需的独立坐标数
  
  一个质点在空间中：3 个自由度
  一个质点在平面上：2 个自由度
  一个质点在曲线上：1 个自由度
  
  刚体在空间中：6 个自由度（3 平动 + 3 转动）
  刚体在平面上：3 个自由度（2 平动 + 1 转动）
```

### 虚位移

```
  虚位移 δr⃗：在约束允许的条件下，
  从当前位置出发的任何微小的假想位移。
  
  "虚"的含义：
  ① 是假想的，不是实际发生的
  ② 是瞬时的（不涉及时间）
  ③ 必须与约束相容
```

```
    虚位移的例子：
    
    ① 在光滑面上的质点：
       虚位移必须沿面的切线方向
    
       ╱╱╱╱╱（光滑面）
        ●→ δr⃗（沿面移动）
    
    ② 连杆机构中的虚位移：
       各点的虚位移之间有约束关系
    
       ● A ─→ δr_A
       │
       │ 刚杆
       │
       ● B ─→ δr_B
       
       δr_A 和 δr_B 有几何关系
```

### 虚功

```
  力 F⃗ 在虚位移 δr⃗ 上做的功：
  
  δW = F⃗ · δr⃗ = F_x·δx + F_y·δy + F_z·δz
```

### 虚位移原理（虚功原理）

```
  ┌──────────────────────────────────────────────────┐
  │                                                  │
  │  具有理想约束的质点系平衡的充要条件是：            │
  │                                                  │
  │  所有主动力在任何虚位移上所做的                    │
  │  虚功之和等于零。                                 │
  │                                                  │
  │  ΣF⃗_i · δr⃗_i = 0                               │
  │                                                  │
  │  即 Σ(F_ix·δx_i + F_iy·δy_i + F_iz·δz_i) = 0   │
  │                                                  │
  └──────────────────────────────────────────────────┘
  
  理想约束：约束力在虚位移上不做功
  （光滑面、铰链、刚性杆等都是理想约束）
```

### 虚位移原理的优势

```
  传统方法（静力学平衡）：
  → 需要求出所有约束力
  → 对多体系统要拆开分别画受力图
  → 方程多，计算量大
  
  虚位移原理：
  → 不需要求约束力！
  → 只需要关注主动力
  → 一个虚功方程就可以求一个未知量
  → 对复杂机构特别高效
```

### 例题：杠杆平衡

```
    杠杆（忽略自重）：
    
    F₁↓              ↑F₂
    ● A──────────△──────● B
    ├─── a ──────┤──b──┤
                 O（支点）
    
    给虚位移：杠杆绕 O 转 δφ
    
    A 的虚位移：δy_A = a·δφ（向下）
    B 的虚位移：δy_B = b·δφ（向上）
    
    虚功方程：
    δW = F₁·a·δφ - F₂·b·δφ = 0
    
    ∴ F₁·a = F₂·b
    
    → 直接得到杠杆原理！不用求支点反力！
```

### 例题：楔块问题

```
    楔块系统（光滑接触面）：
    
    F →  ┌──────┐
         │      ╲ α
         │       ╲
         │        ╲────────────
         │        │ W（重物）  │
         └────────│            │
                  └────────────┘
                       ↑ N（不用求！）
    
    给虚位移：楔块向右移 δx
    
    重物上升：δy = δx · tanα
    
    虚功方程：
    F·δx - W·δy = 0
    F·δx - W·δx·tanα = 0
    
    ∴ F = W·tanα
    
    → 无需画复杂受力图，也不用求法向力 N！
```

## 6.3 广义坐标与拉格朗日方程（简介）

虚位移原理的推广，是分析力学的基石。

### 广义坐标

用最少数量的独立坐标描述系统的位置：

```
  系统自由度 = n
  需要 n 个广义坐标 q₁, q₂, ..., q_n
  
  例：
  单摆  → 1 个自由度 → q = θ（摆角）
  双摆  → 2 个自由度 → q₁ = θ₁, q₂ = θ₂
```

### 拉格朗日方程

```
  ┌──────────────────────────────────┐
  │                                  │
  │  d  ∂L     ∂L                   │
  │ ── ───── - ──── = Q_j           │
  │ dt ∂q̇_j   ∂q_j                 │
  │                                  │
  │  L = T - V（拉格朗日函数）       │
  │  T：动能                         │
  │  V：势能                         │
  │  Q_j：广义力                     │
  │  j = 1, 2, ..., n               │
  │                                  │
  └──────────────────────────────────┘
  
  当所有力都是保守力时：Q_j = 0
  
  d  ∂L     ∂L
  ── ───── - ──── = 0
  dt ∂q̇_j   ∂q_j
```

### 例题：单摆的拉格朗日方程

```
    O───────╲
    │   l    ╲
    │     θ   ●m
    │
    
    广义坐标：q = θ
    
    T = ½m(lθ̇)² = ½ml²θ̇²
    V = -mgl·cosθ（取 O 为势能零点）
    L = T - V = ½ml²θ̇² + mgl·cosθ
    
    ∂L/∂θ̇ = ml²θ̇
    d/dt(∂L/∂θ̇) = ml²θ̈
    ∂L/∂θ = -mgl·sinθ
    
    拉格朗日方程：
    ml²θ̈ + mgl·sinθ = 0
    
    即：θ̈ + (g/l)·sinθ = 0
    
    小角度近似（sinθ ≈ θ）：
    θ̈ + (g/l)·θ = 0  ← 简谐运动方程
    
    周期 T = 2π√(l/g)
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| F* = -ma | 惯性力 |
| M*_c = -J_c·α | 惯性力偶矩 |
| ΣF + F* = 0 | 达朗贝尔原理 |
| Σ F⃗_i · δr⃗_i = 0 | 虚位移原理 |

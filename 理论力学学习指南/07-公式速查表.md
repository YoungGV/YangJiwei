# 理论力学公式速查表

## 一、静力学

### 力矩与力偶

| 公式 | 说明 |
|------|------|
| M_O(F) = ±F·d | 力对点之矩，d 为力臂 |
| M = F·d | 力偶矩，d 为力偶臂 |
| M_合 = ΣM_i | 力偶系的合成 |

### 平衡方程

| 力系类型 | 方程 | 独立方程数 |
|----------|------|-----------|
| 平面汇交力系 | ΣF_x=0, ΣF_y=0 | 2 |
| 平面平行力系 | ΣF_y=0, ΣM_O=0 | 2 |
| 平面一般力系 | ΣF_x=0, ΣF_y=0, ΣM_O=0 | 3 |
| 空间一般力系 | ΣF_x=0, ΣF_y=0, ΣF_z=0, ΣM_x=0, ΣM_y=0, ΣM_z=0 | 6 |

### 摩擦

| 公式 | 说明 |
|------|------|
| F_s ≤ μ_s·F_N | 最大静摩擦力 |
| F_f = μ·F_N | 滑动摩擦力 |
| tanφ = μ_s | 摩擦角（自锁条件） |

### 约束类型速查

| 约束 | 未知量数 | 约束力方向 |
|------|---------|-----------|
| 柔索 | 1 | 沿绳拉力 |
| 光滑面 | 1 | 法向 |
| 滚动支座 | 1 | 垂直支承面 |
| 铰链 | 2 | F_x, F_y |
| 固定端 | 3 | F_x, F_y, M |

## 二、运动学

### 点的运动

| 公式 | 说明 |
|------|------|
| v_x = ẋ, v_y = ẏ | 直角坐标法速度 |
| v = √(v_x² + v_y²) | 速度大小 |
| a_τ = dv/dt = s̈ | 切向加速度 |
| a_n = v²/ρ | 法向加速度 |
| a = √(a_τ² + a_n²) | 总加速度 |

### 刚体定轴转动

| 公式 | 说明 |
|------|------|
| ω = dφ/dt = φ̇ | 角速度 |
| α = dω/dt = φ̈ | 角加速度 |
| v = Rω | 转动上点的线速度 |
| a_τ = Rα | 转动上点的切向加速度 |
| a_n = Rω² | 转动上点的法向加速度 |
| ω = 2πn/60 | 转速换算（n: r/min） |

### 匀变速转动

| 公式 | 说明 |
|------|------|
| ω = ω₀ + αt | 角速度 |
| φ = ω₀t + ½αt² | 角位移 |
| ω² = ω₀² + 2αφ | 速度-位移关系 |

### 合成运动

| 公式 | 说明 |
|------|------|
| v⃗_a = v⃗_r + v⃗_e | 速度合成（矢量加法） |
| a⃗_a = a⃗_r + a⃗_e + a⃗_c | 加速度合成（牵连转动） |
| a⃗_c = 2ω⃗_e × v⃗_r | 科氏加速度 |

### 刚体平面运动

| 公式 | 说明 |
|------|------|
| v⃗_B = v⃗_A + ω × r⃗_BA | 基点法（速度） |
| v_B = ω·PB | 瞬心法（P 为瞬心） |

## 三、动力学

### 基本定律

| 公式 | 说明 |
|------|------|
| F⃗ = ma⃗ | 牛顿第二定律 |
| ΣF_τ = m·a_τ | 自然坐标切向方程 |
| ΣF_n = mv²/ρ | 自然坐标法向方程 |
| J_z·α = ΣM_z | 定轴转动方程 |

### 动量与动量定理

| 公式 | 说明 |
|------|------|
| p⃗ = mv⃗ | 质点动量 |
| p⃗ = Mv⃗_c | 质点系动量 |
| dp⃗/dt = ΣF⃗(外) | 动量定理 |
| ΣF(外)=0 → p=常量 | 动量守恒 |

### 动量矩（角动量）

| 公式 | 说明 |
|------|------|
| L_O = mvd | 质点对 O 的动量矩 |
| L_z = J_z·ω | 定轴转动角动量 |
| dL_z/dt = ΣM_z(外) | 动量矩定理 |
| ΣM_z(外)=0 → J_zω=常量 | 角动量守恒 |

### 转动惯量

| 形体 | 转轴 | J |
|------|------|---|
| 细杆 (m, l) | 过中心⊥杆 | ml²/12 |
| 细杆 (m, l) | 过端点⊥杆 | ml²/3 |
| 圆盘 (m, R) | 过中心⊥面 | mR²/2 |
| 圆环 (m, R) | 过中心⊥面 | mR² |
| 球体 (m, R) | 过球心 | 2mR²/5 |
| **平行轴定理** | — | **J_z = J_c + md²** |

### 功与动能

| 公式 | 说明 |
|------|------|
| W = Fs·cosα | 常力的功 |
| W_G = mgh | 重力的功（h 为下降高度） |
| W_弹 = ½k(x₁²-x₂²) | 弹簧力的功 |
| W_M = M·φ | 力偶的功 |
| P = Fv·cosα = Mω | 功率 |

### 动能

| 运动类型 | 动能 T |
|----------|--------|
| 质点 | ½mv² |
| 平动刚体 | ½Mv_c² |
| 定轴转动刚体 | ½Jω² |
| 平面运动刚体 | ½Mv_c² + ½J_cω² |

### 动能定理与机械能

| 公式 | 说明 |
|------|------|
| T₂ - T₁ = ΣW | 动能定理 |
| T₁ + V₁ = T₂ + V₂ | 机械能守恒（仅保守力做功） |
| V_g = mgh | 重力势能 |
| V_e = ½kx² | 弹性势能 |

## 四、分析力学

| 公式 | 说明 |
|------|------|
| F* = -ma | 惯性力 |
| M*_c = -J_c·α | 惯性力偶 |
| ΣF⃗_i·δr⃗_i = 0 | 虚位移原理（平衡条件） |
| L = T - V | 拉格朗日函数 |
| d/dt(∂L/∂q̇_j) - ∂L/∂q_j = Q_j | 拉格朗日方程 |

## 五、三大定理选择指南

```
  求什么？          用什么定理？
  ─────────────────────────────────
  速度大小（标量）→  动能定理
  速度（矢量）    →  动量定理
  角速度          →  动量矩定理
  力/加速度       →  牛顿定律 / 达朗贝尔
  平衡/约束力     →  虚位移原理 / 静力学
  时间            →  动量定理
  位移            →  动能定理
```

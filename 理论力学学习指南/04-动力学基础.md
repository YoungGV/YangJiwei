# 第四章 动力学基础

动力学研究**力与运动的关系**，是理论力学的核心。

## 4.1 牛顿运动定律

### 三大定律

```
  第一定律（惯性定律）：
  不受力的物体保持静止或匀速直线运动状态。
  
  第二定律（运动定律）：
  ┌────────────────────────────┐
  │                            │
  │  F⃗ = m · a⃗               │
  │                            │
  │  或分量形式：               │
  │  ΣF_x = m·a_x             │
  │  ΣF_y = m·a_y             │
  │  ΣF_z = m·a_z             │
  └────────────────────────────┘
  
  第三定律（作用与反作用）：
  F⃗₁₂ = -F⃗₂₁
```

### 自然坐标形式的运动方程

```
  ┌──────────────────────────┐
  │  ΣF_τ = m · a_τ = m·s̈   │  ← 改变速度大小
  │                          │
  │  ΣF_n = m · a_n = mv²/ρ │  ← 改变速度方向
  └──────────────────────────┘
```

## 4.2 质心与质心运动定理

### 质心位置

```
  ┌──────────────────────────────────┐
  │         Σ m_i · r⃗_i             │
  │  r⃗_c = ──────────────           │
  │           Σ m_i                  │
  │                                  │
  │  分量形式：                      │
  │  x_c = Σm_i·x_i / M             │
  │  y_c = Σm_i·y_i / M             │
  │  z_c = Σm_i·z_i / M             │
  │                                  │
  │  M = Σm_i（总质量）              │
  └──────────────────────────────────┘
```

### 质心运动定理

```
  ┌──────────────────────────────┐
  │                              │
  │  M · a⃗_c = ΣF⃗_i(外)       │
  │                              │
  │  质心的运动只取决于外力，     │
  │  与内力无关！                 │
  │                              │
  │  分量形式：                   │
  │  M·ẍ_c = ΣF_ix(外)          │
  │  M·ÿ_c = ΣF_iy(外)          │
  └──────────────────────────────┘
```

## 4.3 动量定理

### 动量的定义

```
  质点：p⃗ = m·v⃗
  
  质点系：p⃗ = Σm_i·v⃗_i = M·v⃗_c（= 总质量 × 质心速度）
```

### 冲量

```
  I⃗ = ∫F⃗ dt     （从 t₁ 到 t₂ 的积分）
  
  常力的冲量：I⃗ = F⃗ · Δt
```

### 动量定理

```
  ┌───────────────────────────────────────┐
  │  质点：                               │
  │  m·v⃗₂ - m·v⃗₁ = ΣI⃗_i               │
  │  动量的变化 = 冲量之和                │
  │                                       │
  │  质点系：                              │
  │  M·v⃗_c2 - M·v⃗_c1 = ΣI⃗_i(外)       │
  │  系统动量变化 = 外力冲量之和           │
  │  （内力冲量互相抵消）                  │
  │                                       │
  │  微分形式：dp⃗/dt = ΣF⃗(外)           │
  └───────────────────────────────────────┘
```

### 动量守恒条件

```
  若 ΣF⃗(外) = 0  →  p⃗ = 常矢量（动量守恒）
  
  若 ΣF_x(外) = 0  →  p_x = 常量（x方向动量守恒）
```

### 典型应用：碰撞与反冲

```
    子弹打入木块（完全非弹性碰撞）：
    
    碰前：m·v₀ + M·0
    碰后：(m+M)·v
    
    ─→ v₀         ■ 静止
    ●──→           ■
    m              M
    
    碰后合体：
    ●■ ──→ v
    m+M
    
    由动量守恒：m·v₀ = (m+M)·v
    v = m·v₀ / (m+M)
```

## 4.4 动量矩定理（角动量定理）

### 动量矩（角动量）

```
  质点对 O 点的动量矩：
  L_O = m·v·d    （d = O 点到速度矢量的垂直距离）
  
  矢量形式：L⃗_O = r⃗ × m·v⃗
```

```
    动量矩的图示：
    
           v⃗ →
           ●────→
          ╱ m
         ╱
        ╱  d（O 到 v⃗ 的垂距）
       ╱
      O
    
    L_O = m·v·d（标量形式）
    逆时针为正
```

### 动量矩定理

```
  ┌──────────────────────────────────────────┐
  │  质点对 O 点：                            │
  │  dL_O/dt = ΣM_O(F)                      │
  │  动量矩的变化率 = 外力矩之和              │
  │                                          │
  │  质点系对 O 点：                          │
  │  dL_O/dt = ΣM_O(F_i 外)                 │
  │  系统角动量变化率 = 外力矩之和            │
  │                                          │
  │  对固定轴 z：                             │
  │  dL_z/dt = ΣM_z(F_i 外)                 │
  └──────────────────────────────────────────┘
```

### 动量矩守恒条件

```
  若 ΣM_O(F 外) = 0  →  L_O = 常量（角动量守恒）
  
  经典例子：花样滑冰转体
  
      缩手时：              张手时：
       ╱│╲                 ─┼─
       │                    │
      ╱│╲                  ╱ ╲
      
   I小 → ω大（转快）    I大 → ω小（转慢）
   
   因为 L = Iω = 常量
```

## 4.5 转动惯量

### 定义

```
  ┌─────────────────────────┐
  │                         │
  │  J_z = Σ m_i · r_i²    │
  │                         │
  │  r_i：各质点到 z 轴距离 │
  │  单位：kg·m²            │
  └─────────────────────────┘
  
  连续体：J_z = ∫ r² dm
```

### 常见形体的转动惯量

| 形体 | 转轴 | 转动惯量 J |
|------|------|-----------|
| 细长杆（质量 m, 长 l） | 过中心，⊥杆 | ml²/12 |
| 细长杆 | 过端点，⊥杆 | ml²/3 |
| 均质圆盘（质量 m, 半径 R） | 过中心，⊥盘面 | mR²/2 |
| 均质圆环 | 过中心，⊥面 | mR² |
| 均质球体 | 过球心 | 2mR²/5 |

```
    杆过中心转动：          杆过端点转动：
    
        ⊥ 转轴                ⊥ 转轴
        │                     │
    ────●────                 ●────────
    ←l/2→←l/2→                ←── l ──→
    J = ml²/12               J = ml²/3
```

### 平行轴定理

```
  ┌──────────────────────────────────┐
  │                                  │
  │  J_z = J_c + m·d²               │
  │                                  │
  │  J_c：过质心轴的转动惯量         │
  │  d  ：两平行轴之间的距离         │
  │  m  ：物体总质量                 │
  └──────────────────────────────────┘
```

```
    平行轴定理图示：
    
    z 轴     z_c 轴（过质心）
    │          │
    │←── d ──→│
    │          ● 质心
    │          │
    
    J_z = J_c + m·d²
    
    质心轴的 J 最小！
```

## 4.6 定轴转动的运动方程

```
  ┌──────────────────────────────┐
  │                              │
  │  J_z · α = ΣM_z(F_i 外)     │
  │                              │
  │  J_z：对转轴的转动惯量       │
  │  α = φ̈：角加速度             │
  │  ΣM_z：外力矩之和            │
  │                              │
  │  类比：ma = F                │
  │        J α = M               │
  └──────────────────────────────┘
```

### 例题：飞轮制动

```
    飞轮 J = 50 kg·m²，初始转速 n₀ = 300 r/min
    制动力矩 M = -100 N·m
    求：停转时间和转过圈数
    
    解：
    ω₀ = 2π×300/60 = 10π rad/s
    
    J·α = M  →  α = M/J = -100/50 = -2 rad/s²
    
    停转：ω = ω₀ + αt = 0
    t = -ω₀/α = 10π/2 = 5π ≈ 15.7 s
    
    φ = ω₀t + ½αt² = 10π×5π + ½×(-2)×(5π)²
      = 50π² - 25π² = 25π² ≈ 246.7 rad
    
    圈数 = 246.7/(2π) ≈ 39.3 圈
```

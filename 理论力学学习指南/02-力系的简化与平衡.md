# 第二章 力系的简化与平衡

## 2.1 力系分类

```
  力系 ┬─ 汇交力系 ── 所有力的作用线交于一点
       │
       ├─ 平行力系 ── 所有力的作用线相互平行
       │
       ├─ 力偶系   ── 由若干力偶组成
       │
       ├─ 平面一般力系 ── 力在同一平面内，不汇交
       │
       └─ 空间一般力系 ── 最一般的情况
```

---

## 2.2 汇交力系

### 合成（力的多边形法则）

```
    三个汇交力的合成：
    
    F₁→    ↗F₂      F₃↓
      ╲  ╱          │
        ●（汇交点）
    
    几何法（力多边形）：
    
    ──→ F₁
          ╲
           ╲→ F₂
              │
              ↓ F₃
    ─────────→
        F_R（合力 = 封闭边）
    
    解析法：
    F_Rx = ΣF_ix = F₁cosα₁ + F₂cosα₂ + ...
    F_Ry = ΣF_iy = F₁sinα₁ + F₂sinα₂ + ...
    
    F_R = √(F_Rx² + F_Ry²)
    tanθ = F_Ry / F_Rx
```

### 汇交力系的平衡条件

```
  ┌──────────────────────────────┐
  │  合力 F_R = 0                │
  │                              │
  │  等价于：                    │
  │    ΣF_x = 0                 │
  │    ΣF_y = 0                 │
  │   （平面汇交力系）           │
  │                              │
  │    ΣF_x = 0                 │
  │    ΣF_y = 0   （空间）       │
  │    ΣF_z = 0                 │
  └──────────────────────────────┘
```

## 2.3 力的平移定理

**核心定理**：可以将力从一个作用点平移到另一个点，但必须**附加一个力偶**。

```
    原始：力 F 作用在 A 点
    
           F →
    ───────●──────
           A
    
    平移到 O 点：
    
      F →
    ──●─────────── + ⟳ M = F·d
      O
    
    附加力偶 M = F × d（F 到 O 的力矩）
```

```
  ┌─────────────────────────────────────┐
  │  力的平移定理：                       │
  │                                     │
  │  作用在 A 点的力 F，                 │
  │  平移到 O 点 = F（在O点）+ 力偶 M   │
  │                                     │
  │  M = M_O(F)（F 对 O 点之矩）        │
  └─────────────────────────────────────┘
```

## 2.4 平面一般力系的简化

### 向一点简化（向 O 点简化）

```
    把每个力平移到 O 点：

    原力系：F₁, F₂, F₃, ...
                    ↓ 平移
    O 点的力系 + 力偶：
    
    ┌───────────────────────────────────┐
    │  主矢：F_R' = ΣF_i              │
    │       （所有力的矢量和）          │
    │                                   │
    │  主矩：M_O = ΣM_O(F_i)          │
    │       （所有力对 O 点之矩的和）   │
    └───────────────────────────────────┘
```

### 简化结果的讨论

```
  主矢 F_R'    主矩 M_O    最终结果
  ──────────  ──────────  ──────────────────
    = 0          = 0       平衡
    = 0          ≠ 0       合力偶（M_O）
    ≠ 0          = 0       合力（过 O 点）
    ≠ 0          ≠ 0       合力（不过 O 点）
                           合力作用线距 O 点：
                           d = M_O / F_R'
```

```
    最后一种情况的图示：
    
    原本简化到 O 点：
    ──●── F_R' →    + ⟳ M_O
      O
    
    等价于一个合力，但作用线不过 O：
    
    ──────────────
      O     ↑ d = M_O / F_R'
            │
    ────────●── F_R →
            │ 合力作用线
```

## 2.5 平面一般力系的平衡方程

### 基本形式（一矩式）

```
  ┌──────────────────────────┐
  │                          │
  │  ΣF_x = 0    ← 力平衡   │
  │  ΣF_y = 0    ← 力平衡   │
  │  ΣM_O = 0    ← 矩平衡   │
  │                          │
  │  3 个方程，求 3 个未知量  │
  └──────────────────────────┘
```

### 二矩式

```
  ΣF_x = 0
  ΣM_A = 0
  ΣM_B = 0
  
  条件：x 轴不垂直于 AB 连线
```

### 三矩式

```
  ΣM_A = 0
  ΣM_B = 0
  ΣM_C = 0
  
  条件：A、B、C 三点不共线
```

## 2.6 典型例题

### 例题1：简支梁

```
    载荷图：
         F = 10 kN
         ↓
    △════╪════════════○
    A    C              B
    ├─2m─┤├────3m─────┤

    受力图：
         10 kN
         ↓
    ─────╪──────────────
    ↑                   ↑
    R_Ay                R_B
    →
    R_Ax

    求解：
    ΣF_x = 0:  R_Ax = 0
    
    ΣM_A = 0:  -10×2 + R_B×5 = 0
               R_B = 4 kN ↑
    
    ΣM_B = 0:  R_Ay×5 - 10×3 = 0
               R_Ay = 6 kN ↑
    
    验证：ΣF_y = 6 - 10 + 4 = 0 ✓
```

### 例题2：带力偶的悬臂梁

```
    载荷图：
                    M = 6 kN·m
    ▌════════════════╪════════
    A                C        B
    ├─────3m─────────┤──2m───┤
    q = 2 kN/m（全长均布）
    ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓

    受力图：
    → R_Ax     ↓↓↓↓↓↓↓↓↓↓↓↓↓  q=2kN/m
    ↑ R_Ay     ⟳M=6kN·m
    ⟳ M_A
    ▌─────────────────────────
    A                          B

    求解：
    ΣF_x = 0:  R_Ax = 0
    
    ΣF_y = 0:  R_Ay - q×5 = 0
               R_Ay = 10 kN ↑
    
    ΣM_A = 0:  M_A + 6 - 2×5×2.5 = 0
               M_A = 25 - 6 = 19 kN·m ⟲
```

### 例题3：桁架（节点法）

```
    简单桁架：
    
          C
         ╱╲
        ╱  ╲     F↓
       ╱    ╲
      ╱      ╲
    A──────────B
    △          ○
    
    节点 C 的受力图（二力杆原理）：
    
         F↓
          ●C
        ╱   ╲
    N_AC      N_BC
    ╱           ╲
    
    由 ΣF_y = 0 和 ΣF_x = 0 求各杆内力
```

## 2.7 平面平行力系

所有力相互平行时，只有 2 个独立方程：

```
  ΣF_y = 0      （合力为零）
  ΣM_O = 0      （合力矩为零）
  
  → 只能求 2 个未知量
```

## 2.8 空间力系的平衡方程

空间一般力系有 **6 个独立方程**：

```
  ┌──────────────────────┐
  │  ΣF_x = 0            │
  │  ΣF_y = 0            │
  │  ΣF_z = 0            │
  │  ΣM_x = 0            │
  │  ΣM_y = 0            │
  │  ΣM_z = 0            │
  │                      │
  │  6 个方程，6 个未知量  │
  └──────────────────────┘
```

## 2.9 摩擦

### 静摩擦力

```
  0 ≤ F_s ≤ F_s_max = μ_s · F_N
  
  μ_s：静摩擦系数
  F_N：法向压力
  
  静摩擦力大小由平衡条件决定，
  方向与相对运动趋势相反。
```

### 滑动摩擦力

```
  F_f = μ · F_N
  
  μ：动摩擦系数（μ < μ_s）
  方向与相对运动方向相反
```

### 摩擦角

```
         F_N
          ↑
          │╲  全反力 F_R
          │ α╲
          │   ╲
    ──────●─────→ F_f
    
    tanφ = F_f_max / F_N = μ_s
    
    φ：摩擦角
    
    当外力的作用线在摩擦角之内时，
    无论力多大，物体都不会滑动 ── "自锁"
```

## 本章公式总结

| 公式 | 用途 |
|------|------|
| F_R = √(F_Rx² + F_Ry²) | 合力大小 |
| M_O(F) = F · d | 力矩 |
| ΣF_x = 0, ΣF_y = 0, ΣM_O = 0 | 平面一般力系平衡 |
| d = M_O / F_R' | 合力作用线到简化中心的距离 |
| F_s_max = μ_s · F_N | 最大静摩擦力 |
| tanφ = μ_s | 摩擦角 |

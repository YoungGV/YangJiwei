# 第一章 静力学基础

静力学研究物体在力的作用下的**平衡条件**，是整个力学的起点。

## 1.1 力的基本概念

### 力的定义

力是物体间的**相互作用**，使物体的运动状态发生改变或使物体发生变形。

### 力的三要素

```
  力的三要素：
  
  ① 大小  ── 用数值表示，单位 N（牛顿）或 kN
  ② 方向  ── 力的作用线方向和指向
  ③ 作用点 ── 力作用在物体上的位置
  
  力是矢量，用 F⃗ 表示
  
              F⃗
           ╱
         ╱  （方向）
       ╱
      ●───────→ 作用线
   作用点
```

### 力的基本性质

```
  公理1（二力平衡）：
  作用在刚体上的两个力平衡的充要条件是——
  大小相等、方向相反、作用在同一直线上。
  
     ← F   ●━━━━━━━━●   F →
  
  公理2（加减平衡力系）：
  在刚体上加上或减去一个平衡力系，
  不改变原力系对刚体的作用效果。
  
  公理3（力的平行四边形法则）：
  两个共点力的合力等于以这两个力
  为邻边所构成的平行四边形的对角线。
  
        F_R ╱│
          ╱  │ F₂
        ╱   │
      ●──────┘
        F₁
  
  公理4（作用与反作用）：
  作用力与反作用力大小相等、方向相反、
  沿同一直线，分别作用在两个物体上。
  
     物体A │← F  F →│ 物体B
```

## 1.2 力矩（Moment of Force）

### 力对点之矩

力使物体绕某点转动的效果。

```
  ┌────────────────────────────────────┐
  │                                    │
  │  M_O(F) = ± F · d                 │
  │                                    │
  │  F：力的大小                       │
  │  d：力臂（O 点到力作用线的垂直距离）│
  │  单位：N·m                         │
  │                                    │
  └────────────────────────────────────┘
```

```
    力矩示意图：
    
              F
           ↗
         ╱
       ╱     d（力臂）
      ●─ ─ ─ ─ ─ ─ ┐
      O              │
                     ↓ F的作用线
    
    M_O(F) = F × d
    逆时针为正 ⟳(+)
    顺时针为负 ⟲(-)
```

### 合力矩定理

合力对某点之矩等于各分力对同一点之矩的代数和：

```
  M_O(F_R) = Σ M_O(F_i)
```

> 这个定理使我们可以将力分解为两个分量后分别求矩再相加，简化计算。

### 力对轴之矩

力使物体绕某轴转动的效果：

```
  M_z(F) = F的投影在垂直于z轴的平面上分量 × 力臂
  
  特别地：
  • 力的作用线与轴相交 → M = 0
  • 力的作用线与轴平行 → M = 0
```

## 1.3 力偶（Couple）

### 力偶的定义

两个大小相等、方向相反、不共线的力组成**力偶**。

```
    力偶示意：
    
    ↑ F
    │
    │←── d（力偶臂）──→│
    │                   │
                        ↓ F
    
    力偶矩 M = F × d
    力偶没有合力，只产生转动效果！
```

### 力偶的性质

```
  ┌──────────────────────────────────────────┐
  │  力偶的三个重要性质：                      │
  │                                          │
  │  ① 力偶的合力为零（ΣF = 0）              │
  │     → 力偶不能用一个力来平衡              │
  │     → 只能用另一个力偶来平衡              │
  │                                          │
  │  ② 力偶对任意点的矩都相等                 │
  │     → 力偶矩 M = F·d 与矩心无关          │
  │                                          │
  │  ③ 力偶的等效条件：                       │
  │     力偶矩 M 相同（大小+转向）             │
  │     → 两个力偶等效                        │
  └──────────────────────────────────────────┘
```

### 力偶系的合成

同一平面内多个力偶的合力偶矩 = 各力偶矩的代数和：

```
  M = Σ M_i = M₁ + M₂ + ... + M_n
```

## 1.4 约束与约束力

### 自由体与非自由体

```
  自由体 ── 可以在空间中自由运动的物体（如抛出的球）
  非自由体 ── 运动受到限制的物体（如桌上的书）
  
  约束 ── 限制物体运动的装置
  约束力（反力）── 约束对物体施加的力
```

### 常见约束类型

#### ① 柔性约束（绳索、链条）

```
    只能承受拉力，沿绳索方向背离物体
    
    ╱╱╱╱╱╱╱╱╱（天花板）
        │ T（拉力）
        │
        ●（重物）
        ↓ W
```

#### ② 光滑接触面约束

```
    只有法向压力，垂直于接触面指向物体
    
        ● 物体
       ╱│
      ╱ │ F_N（法向反力）
     ╱  ↓
    ╱╱╱╱╱╱╱（光滑面）
```

#### ③ 铰链约束（圆柱铰链）

```
    可以转动但不能移动，约束力过铰链中心
    方向未知，用两个分量表示
    
       ↑ F_Ay
       │
    ───●─── → F_Ax
       │
       A（铰链）
    
    约束力：F_Ax（水平分量）+ F_Ay（竖直分量）
```

#### ④ 固定端约束（嵌入端）

```
    既不能移动也不能转动
    有两个力分量 + 一个力偶矩
    
    ▌───────────
    ▌  → F_Ax
    ▌  ↑ F_Ay
    ▌  ⟳ M_A
    ▌
    
    约束力：F_Ax + F_Ay + M_A（三个未知量）
```

#### ⑤ 滚动支座（可动铰支座）

```
    可以沿支承面滑动，只产生垂直于支承面的反力
    
    ═══════════
        ○
        ↑ F_N（一个未知量）
    ────────────
```

### 约束力汇总表

| 约束类型 | 示意 | 未知量个数 | 反力方向 |
|----------|------|-----------|---------|
| 柔索 | 绳 | 1 | 沿绳背离物体 |
| 光滑面 | 面接触 | 1 | 法线方向 |
| 滚动支座 | △○ | 1 | 垂直支承面 |
| 圆柱铰链 | ○ | 2 | 任意（分解为 x, y） |
| 固定端 | ▌ | 3 | 两个力分量 + 一个力偶 |

## 1.5 受力分析与受力图

**受力分析是理论力学最核心的基本功！**

### 画受力图的步骤

```
  ┌───────────────────────────────────────┐
  │  受力图四步法：                        │
  │                                       │
  │  ① 选取研究对象（取隔离体）            │
  │  ② 画主动力（重力、外力等）            │
  │  ③ 画约束力（按约束类型确定）           │
  │  ④ 检查（力的个数、方向是否合理）       │
  └───────────────────────────────────────┘
```

### 典型例题：画受力图

```
    实际结构：简支梁受集中力
    
         F↓
    △════╪══════════○
    A                B
    
    受力图（取梁为研究对象）：
    
         F↓
    ─────╪──────────────
    ↑       ← 梁 →     ↑
    R_Ay                R_B
    →
    R_Ax
    
    A（铰支座）→ 两个未知力 R_Ax, R_Ay
    B（滚动支座）→ 一个未知力 R_B
    共 3 个未知量，恰好可用 3 个平衡方程求解
```

### 多物体系统的受力分析

```
    拆开各物体分别画受力图，注意：
    
    ┌────────────────────────────────────┐
    │  作用力与反作用力定律：              │
    │                                    │
    │  两物体之间的力大小相等、方向相反    │
    │  在各自的受力图上标注相反的力        │
    │                                    │
    │    物体1: ──→ F                    │
    │    物体2: ←── F                    │
    └────────────────────────────────────┘
```

## 1.6 二力构件

**二力构件**（二力杆）：只在两个点受力的构件，其两个力必沿连线方向。

```
    二力杆：
    
    ← F_A ●━━━━━━━━━━━━● F_B →
           A              B
    
    特征：只有两个受力点
    结论：F_A 和 F_B 必沿 AB 连线，大小相等、方向相反
    
    识别二力杆可以大大简化受力分析！
```

### 二力杆的判别方法

```
  满足以下条件的构件就是二力杆：
  
  ✓ 只受两个力（两个力的作用点）
  ✓ 不受力偶作用
  ✓ 自重忽略不计
  
  常见的二力杆：桁架中的杆件、连杆机构中不受外力的连杆
```

## 1.7 力的投影与分解

### 力在坐标轴上的投影

```
    y
    ↑     F⃗
    │   ╱
    │ ╱ α
    │╱────→ x
    O
    
    F_x = F·cosα    （x 轴投影）
    F_y = F·sinα    （y 轴投影）
    
    反过来：
    F = √(F_x² + F_y²)
    tanα = F_y / F_x
```

### 三维力的投影

```
    F_x = F·cosα
    F_y = F·cosβ
    F_z = F·cosγ
    
    cos²α + cos²β + cos²γ = 1（方向余弦关系）
    
    F = √(F_x² + F_y² + F_z²)
```

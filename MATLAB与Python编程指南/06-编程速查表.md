## 五、有限元编程模板

### 刚度矩阵组装（Python）

```python
K = np.zeros((n_dof, n_dof))
for e in range(n_elements):
    Ke = compute_Ke(e)      # 单元刚度矩阵
    dof = get_dof(e)         # 单元自由度编号
    for i in range(len(dof)):
        for j in range(len(dof)):
            K[dof[i], dof[j]] += Ke[i, j]
```

### 边界条件处理

```python
fixed = [0, 1, 3]   # 固定自由度
free = [i for i in range(n_dof) if i not in fixed]
u = np.zeros(n_dof)
u[free] = np.linalg.solve(K[np.ix_(free, free)], F[free])
```

### 应力计算

```python
for e in range(n_elements):
    ue = u[get_dof(e)]
    epsilon = B @ ue         # 应变
    sigma = D @ epsilon      # 应力
```

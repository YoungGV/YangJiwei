## 为什么要学编程？

```
  你的导师方向：结构拓扑优化
       │
       └──→ 需要 MATLAB/Python 编程
            ├── 编写拓扑优化算法（SIMP等）
            ├── 调用有限元求解器
            ├── 处理仿真数据
            ├── 绘制优化结果
            └── 编写 Abaqus 子程序（Python 脚本）
```

## 推荐学习路线

```
  MATLAB 路线（快速入门）：
  矩阵运算 → 绘图 → 解方程组 → 有限元编程 → 拓扑优化

  Python 路线（长期发展）：
  基础语法 → NumPy → Matplotlib → SciPy → FEniCS → 拓扑优化
```
